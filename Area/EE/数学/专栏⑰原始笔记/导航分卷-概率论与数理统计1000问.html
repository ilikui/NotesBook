▎ 随机事件与概率

  1. 古典概型（等可能概型）的”等可能”假设到底意味着什么？抛硬币正反等可能，是因为硬币对称——但如果硬币稍有磨损、重心偏移，还能用古典概型吗？

  2. 条件概率 P(B|A) = P(AB)/P(A)——这个公式是在”缩小样本空间”：已知事件A发生了，样本空间从Ω缩小成A？

  3. 全概率公式和贝叶斯公式到底是什么关系？一个由因推果（已知原因的概率求结果的概率），一个由果推因（已知结果反推哪个原因最可能）。贝叶斯公式的分母不就是全概率公式吗？

  4. 事件独立性和互斥性能同时成立吗？如果P(A)>0且P(B)>0，A和B互斥则P(AB)=0，而独立要求P(AB)=P(A)P(B)>0——所以互斥和独立不能同时成立。那”零概率事件”和”不可能事件”是同一个概念吗？

  5. 实际应用：一道题里给了”甲、乙、丙三人独立破译密码，各自破译的概率是0.8、0.7、0.6”——问”至少一人破译”的概率是1-0.2×0.3×0.4=0.976。为什么用”1减去都没破译”比直接算更简单（因为”至少一人”的事件包含7种情况，用对立事件只有1种）？

  6. n个球放入N个盒子、每个盒子可放任意多球——“至少一个盒子空”的概率怎么算？不能直接用古典概型（每个球的分配独立），用容斥原理：先算1个盒子空的概率，减去2个盒子空的概率……

▎ 一维随机变量

  1. 分布函数F(x)=P{X≤x}为什么必须满足”右连续”而非左连续？因为F(x)定义的是”≤x”——取值恰好等于x的概率是右连续的关键？

  2. 离散型随机变量的分布律（所有可能取值及其概率）为什么要求概率之和为1？这不是数学规定——是”取值总得是这些中的某一个”的逻辑必然？

  3. 连续型随机变量在某点的概率为什么是0？因为概率密度f(x)在单点上的积分是0。那”不可能事件概率为0”和”概率为0的事件不可能发生”是不是一回事——不是！连续型随机变量取某个具体值的概率是0，但这个事件完全可能发生？

  4. 常见离散分布怎么从”生活场景”理解——（1）0-1分布（一次伯努利试验：抛一次硬币）、（2）二项分布B(n,p)（n次独立重复：抛n次硬币中正面次数）、（3）泊松分布P(λ)（单位时间内的随机事件次数：一小时内电话呼入数）、（4）几何分布（首次成功的等待次数：第几次抛才出正面）？

  5. 为什么泊松分布可以近似二项分布？当n很大（n≥100）、p很小（p≤0.1）、np=λ适中时——“稀有事件”的计数近似服从泊松分布？实际中，“某城市一天内交通事故数”为什么更适合用泊松而不是二项分布（因为”每个人是否出事故”的二项试验假设太牵强，但”稀有事件在单位时间内发生的次数”恰好是泊松的典型场景）？

▎ 常见分布深度拆解

  1. 均匀分布 U(a,b)——“等可能”的连续版。为什么说均匀分布是最”无信息”的分布？如果你对某个参数只知道它的范围[a,b]，没有其他信息，均匀分布是最大熵分布？

  2. 指数分布 Exp(λ)——“无记忆性”：P{X>s+t|X>s}=P{X>t}。怎么理解——一个灯泡已经亮了1000小时，它再亮100小时的概率跟一个新灯泡亮100小时的概率一样？所以指数分布适合模拟什么——“永不老化”的产品的寿命（电子元件？还是机械零件——机械零件会磨损，不适合）？

  3. 正态分布 N(μ,σ²)——“三σ原则”：P{|X-μ|<σ}=68.26%、P{|X-μ|<2σ}=95.44%、P{|X-μ|<3σ}=99.74%。为什么说正态分布是”统计学的灵魂”——因为它出现在几乎所有自然现象的平均值分布中（中心极限定理）？

  4. 正态分布标准化——为什么要标准化？因为N(μ,σ²)的分布函数不是初等函数，没法直接算概率。标准化成N(0,1)后查标准正态分布表——所有正态分布的概率计算都归结为查一张表？

  5. 标准正态分布的”上α分位数”u_α——P{X>u_α}=α，比如u_{0.025}=1.96。为什么双边检验常用1.96这个数字——因为95%置信区间对应的就是±1.96σ？

▎ 多维随机变量

  1. 联合分布函数F(x,y)=P{X≤x,Y≤y}——为什么F(x,y)要同时考虑X和Y的”≤“关系？从几何上看，(X,Y)落在以(x,y)为右上角的无穷矩形内的概率？

  2. 边缘分布和联合分布的关系——知道联合分布一定能推出边缘分布（对另一个变量求和或积分），但反过来知道边缘分布能不能推出联合分布——不能，因为缺了”相关性”信息？

  3. 随机变量的独立性——F(x,y)=F_X(x)F_Y(y)。独立性的本质是什么——X取什么值不会影响Y的分布，反之亦然。实际中怎么快速判断——如果联合密度能写成f_X(x)×f_Y(y)的形式（变量分离），就独立？

  4. 二维均匀分布：区域D上的二维均匀分布，联合密度f(x,y)=1/面积(D)如果(x,y)在D内否则0。如果D是单位圆，X和Y的边缘分布——X的密度不是均匀的（因为圆中间”厚”、两端”薄”），所以尽管联合分布是均匀的，边缘分布就不均匀了？

▎ 数字特征

  1. 期望E(X)为什么叫”数学期望”——因为它是随机变量所有可能取值的”加权平均”，权重就是概率。大数定律说当试验次数足够多时，样本均值会趋近于这个期望——所以期望是”我们期望看到的平均值”？

  2. 方差D(X)=E[(X-EX)²]——为什么用平方而不是绝对值？绝对值不好求导、平方有好的数学性质（平方可展开成EX²-(EX)²）。但平方也有问题——量纲是原变量的平方。所以引入了标准差σ=√D(X)？

  3. 协方差Cov(X,Y)=E[(X-EX)(Y-EY)]——Cov>0表示X和Y正相关（X增大时Y也倾向增大）。但协方差的数值大小受量纲影响——比如取不同单位（米vs厘米），协方差会差100倍。所以引入了”无量纲”的相关系数ρ？

  4. 相关系数ρ：ρ在[-1,1]之间。|ρ|=1的充要条件是X和Y以概率1线性相关——Y=aX+b。但ρ=0只说明”不线性相关”，能不能说明”独立”——不能！Y=X²在对称区间上，ρ=0但完全不独立？

  5. 矩——k阶原点矩E(X^k)和k阶中心矩E(X−EX)k。为什么三阶中心矩衡量”偏度”（分布不对称的程度）、四阶中心矩衡量”峰度”（分布的”尖”或”胖”程度）？

  6. 切比雪夫不等式——P{|X-μ|≥ε}≤σ²/ε²——为什么说它”弱”但”普适”？它适用于任意分布（只要方差存在），但给出的上界很宽松——比如ε=2σ时，上界是1/4=25%，而对正态分布实际上只有约4.56%？

▎ 大数定律与中心极限定理

  1. 伯努利大数定律——当n足够大时，事件发生的频率趋近于概率。为什么这被认为是”概率论的基石”？因为它让概率从”抽象的数字”变成了”可观察的现象”？

  2. 辛钦大数定律——独立同分布的随机变量序列的算术平均值依概率收敛于期望。为什么它不要求方差存在——因为切比雪夫大数定律需要方差存在，但辛钦只需要期望存在？

  3. 中心极限定理——为什么说它是”概率论的王冠”？因为无论总体是什么分布（只要方差有限），当样本量足够大时，样本均值的分布近似于正态分布。这就解释了为什么正态分布在自然界如此常见——任何大量独立随机因素叠加的结果都近似正态？

  4. 实际应用：某工厂生产的零件重量服从期望50g、标准差1g的某个未知分布。抽取100个零件称重，“总重量超过5020g”的概率多大？因为100足够大，总重量近似服从N(5000,100)，标准化后查表——不需要知道零件的原始分布？

  5. 为什么中心极限定理在实践中一般要求n≥30才近似成立？如果总体分布是对称的（如均匀分布），n=10左右就够了；但如果总体分布严重偏斜（如指数分布），可能需要n≥50。那n=30这条”经验规则”怎么来的——这是保守情况下的一个通用参考值？

▎ 数理统计基础

  1. 总体和样本——总体是研究对象具有的某个指标的全体。但现实中你永远不可能获取”总体”的全貌（比如”全中国人的身高”），只能通过样本来推断总体。为什么统计学的基础是”用部分推断整体”？

  2. 统计量——不包含任何未知参数的样本的函数。比如样本均值X̄=ΣX_i/n、样本方差S²=Σ(X_i-X̄)²/(n-1)。为什么样本方差的分母用n-1而不是n——因为用n会低估总体方差（“无偏性”要求用n-1）？

  3. 三大抽样分布——χ²分布（标准正态变量的平方和）、t分布（标准正态/√(χ²/n)）、F分布（两个独立χ²/n的比值）。为什么t分布也叫”学生氏分布”——因为发明者戈塞特以”Student”为笔名发表？

  4. t分布和标准正态分布的区别——t分布比正态分布”尾巴更厚”（更易出现极端值），但随着自由度n增大，t分布趋近于正态分布。为什么小样本（n<30）时用t分布而不是正态分布——因为小样本下总体方差未知，用样本标准差S代替时，X̄的分布不再服从正态而是服从t分布？

▎ 参数估计

  1. 点估计的”矩估计法”——用样本矩等于总体矩来解出参数。比如指数分布Exp(λ)只有一个参数λ，E(X)=1/λ，令X̄=1/λ̂，得λ̂=1/X̄。为什么矩估计法在考试里是最简单的估计方法——不需要复杂的推导，解方程就行？

  2. 极大似然估计——找到参数θ使得”当前样本出现的概率最大”。为什么说极大似然估计是”最自然”的估计方法——因为我们已经观测到了这组样本，那么导致这组样本出现概率最大的那个参数值就是最合理的？

  3. 估计量的评价标准——（1）无偏性（估计量的期望等于真值）、（2）有效性（方差越小越好）、（3）一致性（样本量增大时估计量趋近于真值）。哪个标准最重要——一致性：因为样本量足够大时你总能逼近真值，但无偏性在小样本下更重要？

  4. 置信区间——95%置信区间不是”参数以95%的概率落在区间内”——而是”如果重复抽样100次，大约95次的置信区间会包含真值”。参数是一个固定的数（不是随机变量），所以不能谈”概率落在区间内”——那应该说：区间是随机变量，真值是固定值？

▎ 假设检验

  1. 原假设H₀和备择假设H₁怎么设——通常原假设是”保守的”、“无差异的”（新药无效），备择假设是”有差异的”（新药有效）。为什么不能反过来设——因为统计学的逻辑是”通过拒绝原假设来证明备择假设”？

  2. 两类错误——第一类错误（弃真——原假设为真时拒绝它，概率为α）和第二类错误（取伪——原假设为假时接受它，概率为β）。为什么通常控制α而不控制β——因为α是你能主动控制的风险（你设定显著性水平），β跟样本量、效应大小有关，无法直接控制？

  3. p值的含义——在H₀成立的条件下，出现”当前样本或更极端样本”的概率。如果p<α（通常0.05），拒绝H₀。但p值不是”H₀为真的概率”——这是一个最常见的误解。p值大不能证明H₀为真（“接受H₀”在统计上是不严谨的说法，应该说”没有充分理由拒绝H₀”）？

  4. 单侧检验和双侧检验——什么时候用单侧？如果你关心的是”新药是否比旧药好”（不是”不同”而是”更好”），就用单侧检验。但为什么很多统计学家更推荐双侧检验——因为单侧检验可能”钻空子”（如果效果跟预期相反，单侧检验会错过）？

  5. 两个正态总体均值差的检验——如果σ²已知用U检验（正态分布），σ²未知但相等用t检验。实际中σ²几乎都是未知的——所以大多时候用的是t检验？

▎ 实际应用与算法

  1. 朴素贝叶斯分类器 为什么叫”朴素”——因为它假设所有特征条件独立。这个假设在现实中几乎永远不成立（“买雨衣”和”打雨伞”显然相关），但为什么分类效果还不错——因为分类只需要”相对大小”而不需要”精确概率”？

  2. 蒙特卡洛方法——用随机采样来估计数值（比如用随机点落在圆内的比例来估计π）。为什么说它是”用概率解决确定性问题”——因为把确定性问题的解表示成某个随机变量的期望，然后用大数定律用样本均值来逼近？

  3. 马尔可夫链——“无后效性”：状态转移的概率只依赖于当前状态，不依赖于过去的历史。“未来只通过现在与过去相连”——这个性质为什么有强大威力（它大大简化了复杂的概率模型）？

  4. 贝叶斯统计 vs 频率学派统计——频率学派认为参数是固定的未知常数（没有先验分布），贝叶斯学派认为参数是随机变量（有先验分布+观测数据更新成后验分布）。你在考研里学的主要是频率学派——但为什么说贝叶斯在机器学习里更常见（因为先验可以引入领域知识，适合迭代式学习）？

▎ 考研高频题型速查

  1. 全概率公式+贝叶斯公式的应用题——通常给一个”3个工厂各生产一批产品、次品率不同”的题目。解决套路：第一步设”取到某厂的产品”为完备事件组，第二步用全概率公式求”取到次品的概率”，第三步用贝叶斯公式求”已知次品来自某厂的概率”？

  2. 二维随机变量求期望和协方差——通常给联合分布律或联合密度，让你求E(X)、E(Y)、Cov(X,Y)、ρ_XY。解决套路：先求边缘分布→求期望→求E(XY)→Cov=E(XY)-E(X)E(Y)→ρ=Cov/√(D(X)D(Y))。最容易错的是哪步——E(XY)的计算（必须用联合分布而不是边缘分布）？

  3. 中心极限定理的应用——给一个”随机变量序列”让你估算概率。解决套路：先看n是否足够大→标准化成Z=(X̄-μ)/(σ/√n)→查标准正态分布表。最常见错误——忘了除以√n？

  4. 参数估计的综合题——给一个分布和一个样本，让你同时用矩估计和极大似然估计求参数，并比较优劣。矩估计简单但常常不高效，极大似然估计复杂但有渐进最优性——考试中哪个先做——矩估计先拿分，极大似然再拿满分？

  5. 假设检验的综合题——给一个场景”问新工艺是否改变了产品的均值/方差”。解决套路：先判断单侧/双侧、σ已知/未知、一个总体/两个总体→选检验统计量→计算样本值→查表得临界值→比较得出结论。为什么写步骤比算对数字更重要——因为阅卷看的是你”会不会做”、计算错误扣小分、步骤缺失扣大分？
