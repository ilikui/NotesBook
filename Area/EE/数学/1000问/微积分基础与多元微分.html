考研数学1000问：极限、导数、积分与多元微分

本篇对应专栏⑰题库中“极限与连续、导数与微分、不定积分与定积分、多元函数微分学”四组基础问题。每题给出定义、直觉、适用条件和常见误区。

一、极限与连续

Q1. ε-δ 极限定义到底在说什么？为什么要用“任意小的数”？

答案： (lim_{x\to a}f(x)=L) 的严格定义是：对任意给定的 ( arepsilon>0)，都存在 (delta>0)，使得只要 (0<|x-a|<\delta)，就有 (|f(x)-L|<\varepsilon)。

直觉是：无论别人把输出允许误差 ( arepsilon) 要求得多小，我们都能找到一个输入邻域 (delta)，保证输入足够接近 a 时输出就足够接近 L。它把“无限接近”变成可量化的“任意精度都能保证”。

注意： 极限只描述 x 接近 a 时的函数值，不要求 f(a)=L，甚至 f(a) 可以不存在。

Q2. 两个重要极限的直觉是什么？为什么重要？

答案：

  • 第一个极限：当角度以弧度计且 x 很小时，单位圆上的弧长与对应弦长非常接近，因此 sin x 与 x 的比值趋于 1。它是三角函数求导、等价无穷小和小角度近似的基础。
  • 第二个极限：单位增长率为 1/n、重复 n 次复利，极限趋于 e。它连接连续复利、指数函数、连续增长/衰减和自然对数。

重要之处在于它们能把复杂表达式化成标准极限，并作为后续求导、积分和渐近分析的基本工具。

Q3. 函数在一点连续意味着什么？

答案： 函数 f 在 x=a 连续，当且仅当：

  1. f(a) 有定义；
  2. (lim_{x\to a}f(x)) 存在；
  3. (lim_{x\to a}f(x)=f(a))。

几何直觉是图像在该点没有“断开、跳跃或无限冲向远处”的现象，但连续不等于可导：例如 f(x)=|x| 在 0 连续，却因左右导数不同而不可导。

Q4. 间断点有哪些类型？可去与跳跃间断有什么区别？

答案：

  • 可去间断：左右极限存在且相等，但函数值缺失或不等于该极限；重新定义 f(a) 可修复连续性。
  • 跳跃间断：左右极限都存在且有限，但不相等，图像在该点发生跳跃，单独修改 f(a) 无法修复。
  • 无穷间断：函数值在靠近该点时无界，例如 1/x 在 0 附近。
  • 振荡间断：靠近该点时持续振荡，极限不存在，例如 sin(1/x) 在 0 附近。

判断时分别计算左极限、右极限和函数值，不要只看图形。

二、导数与微分

Q5. 导数的几何意义是什么？为什么 f’(x)=0 不一定是极值？

答案： 导数 f’(a) 是函数在 a 点的瞬时变化率，也是曲线在该点切线的斜率。它描述输入发生微小变化时输出的一阶近似变化。

f’(a)=0 只说明切线水平，不保证极值。例如 f(x)=x³ 在 0 处导数为 0，但函数仍然单调递增，是驻点而非极值点。

二阶导数描述导数的变化率/曲线凹凸性：在满足适用条件时，f’(a)=0 且 f”(a)>0 可判局部极小，f”(a)<0 可判局部极大；若 f”(a)=0 则判别法不确定。

Q6. 罗尔、拉格朗日、柯西中值定理有什么关系？

答案：

  • 罗尔定理：连续闭区间、开区间可导且 f(a)=f(b)，则存在 c 使 f’(c)=0。
  • 拉格朗日中值定理：存在 c 使 (f’(c)=(f(b)-f(a))/(b-a))，即某点瞬时斜率等于区间平均斜率。
  • 柯西中值定理：对 f、g 满足相应连续/可导条件，存在 c 使 ((f(b)-f(a))/(g(b)-g(a))=f’(c)/g’(c))（分母非零等条件需满足）。

拉格朗日定理可看作柯西中值定理令 g(x)=x；罗尔定理又是拉格朗日定理在 f(a)=f(b) 时的特例。

Q7. 洛必达法则什么时候能用？为什么有时越用越复杂？

答案： 常见形式是 0/0 或 ∞/∞。在分子分母满足相应可导条件、分母导数在邻域内不为 0，且导数比值极限存在（或趋于无穷）时，才可据洛必达法则求原比值极限。

使用前先确认确实属于不定式；若是 0×∞、∞−∞、1^∞ 等，需要先变形。若求导后表达式更复杂，可考虑等价无穷小、泰勒展开、夹逼定理或换元。不能对任意分式无条件地“分子分母分别求导”。

Q8. 泰勒展开的本质是什么？为什么局部像多项式？

答案： 泰勒展开用函数在某点的导数构造多项式，使多项式在该点附近尽可能匹配函数的局部变化。以 a 为展开点：

有限阶展开需要带余项，误差大小由更高阶导数或其他余项形式控制。它是局部近似，不保证远离展开点仍准确。

工程应用包括 ADC 非线性近似、传感器标定、控制算法线性化和数值计算误差估计。使用时要说明展开点、阶数、有效区间和误差界。

三、不定积分与定积分

Q9. 不定积分为什么叫“不定”？积分与微分是什么关系？

答案： 不定积分 (int f(x)dx) 表示所有满足 F’(x)=f(x) 的原函数集合，因此结果相差一个任意常数 C，称为原函数族。

微分描述局部变化率；不定积分反过来寻找一个函数，使它的导数等于给定函数。二者在适当条件下互为逆运算，但要注意积分常数和定义域连通性。

Q10. 定积分到底在算什么？黎曼和为什么能表示面积？

答案： 定积分可理解为把区间切成许多小段，对每段的函数值乘以小段宽度求和，再让最大分段宽度趋于 0 的极限：

当 f(x)≥0 时，它表示曲线与 x 轴之间的有向面积；若函数有正有负，定积分是带符号的净累积量。通过选择不同的被积函数和变量变换，也可计算体积、弧长、质量和能量等。

Q11. 微积分基本定理为什么“基本”？

答案： 它建立了微分与定积分之间的核心联系：

  • 若 f 连续，定义 (F(x)=\int_a^x f(t)dt)，则 F’(x)=f(x)。
  • 若 F 是 f 的一个原函数，则 (int_a^b f(x)dx=F(b)-F(a))。

第一部分说明积分累积函数的导数恢复原函数；第二部分让我们通过求原函数计算定积分，避免直接处理黎曼和极限。

Q12. 面积无限大的区域，面积可能有限吗？

答案： 可以。反常积分的区间可能无穷长，或被积函数在端点无界；若相应极限存在且有限，则积分收敛。

四、多元函数微分学

Q13. 偏导数的几何意义是什么？

答案： 对 z=f(x,y)，(partial z/partial x) 表示固定 y 不变，只沿 x 方向变化时 z 的瞬时变化率；(partial z/partial y) 则固定 x 不变，沿 y 方向变化。

几何上，它们是曲面在两个坐标方向截面曲线的切线斜率。偏导数存在只说明沿坐标方向的变化率存在，不自动保证函数在该点整体可微。

Q14. 偏导数存在一定可微吗？

答案： 不一定。可微比偏导存在要求更强：函数在该点附近要能被一个线性函数以比输入距离更快的误差逼近。

反例：

在原点两个偏导数都存在且为 0，但沿 y=x 有 f(x,x)=|x|/sqrt(2)，其相对输入距离的误差比例不趋于 0，因此在原点不可微。

常用充分条件：若偏导数在某邻域存在且在该点连续，则函数在该点可微。连续偏导是充分条件，不是必要条件。
