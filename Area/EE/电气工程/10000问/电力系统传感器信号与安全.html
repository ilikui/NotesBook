电气工程10000问：电力系统、传感器、信号与电气安全

本篇迁移电气工程 10000 问第二批 10 道问答，覆盖标幺值、交流/直流输电、逻辑完备性、配电保护、连续/离散信号、采样混叠、传感器原理与测量量程。电气安全部分涉及配电制式，实际操作必须遵循当地规范并由合格电气专业人员实施。

11. 电力系统为什么使用标幺值（pu）？

答案： 标幺值把实际物理量除以选定基准值，变成无量纲的相对数：

常用三相基准量：

使用标幺值的好处：

  • 跨不同电压等级比较设备和系统状态更直观。
  • 统一容量基准后，变压器阻抗折算更方便。
  • 计算式简化，便于系统潮流、短路和稳定分析。
  • 数值尺度更集中，减少跨数量级计算的复杂度。

边界： 标幺值只是单位归一化，不会改变物理规律。跨变压器换算时必须按变比选择各侧电压基准；只有基准电压按变比匹配时，变压器变比才会在标幺模型中消去。

12. 为什么高压输电历史上以交流为主，现在又发展特高压直流？

答案： 交流输电早期胜出的关键是变压器能高效、经济地升降电压，便于远距离升压输电、用户侧降压配电。现代电力电子技术成熟后，直流换流站可实现大功率 AC/DC 变换，HVDC 在长距离大容量、海底电缆和异步电网互联中有优势。

交流输电（HVAC）直流输电（HVDC）
变压器升降压成熟需要换流站，设备投资高
易接入同步交流电网可连接不同频率/异步电网
长电缆有充电电流问题稳态直流电缆无交流充电电流
多端分支和中间取电较方便多端控制更复杂，方案依赖换流技术

是否采用 HVDC 要比较线路长度、容量、电缆/架空线、换流站成本、损耗和电网稳定要求；不能笼统说直流在所有距离和容量下都更省损耗。

  A[发电侧 AC] --> B[升压变压器]
  B --> C[长距离 HVAC]
  C --> D[降压变电站]
  E[发电侧 AC] --> F[整流换流站]
  F --> G[HVDC 线路 / 海底电缆]
  G --> H[逆变换流站]
  H --> I[受端 AC 电网]

13. 为什么 NAND 或 NOR 单独就能实现任意布尔逻辑？

答案： NAND 和 NOR 都是功能完备逻辑门。以 NAND 为例：

  • NOT A = A NAND A。
  • AND 可由 NAND 输出再取反得到。
  • OR 可用德摩根定律由 NAND 组合实现。

因此只用 NAND 门就能构造任意布尔函数。数字芯片设计中，标准单元库通常包含多种门型，综合工具会根据面积、时序和功耗选择组合，并非只使用一种门。

14. 保护接地、保护接零和 PE/N 有什么区别？

答案： 这是必须按配电系统制式区分的安全概念：

  • PE：保护导体，连接设备外露可导电部分与保护接地系统，正常情况下不应承载工作电流。
  • N：中性导体，正常运行时可能承载工作电流。
  • TN 系统：电源中性点接地，设备外壳通过 PE/PEN 与电源接地点形成保护回路。
  • TT 系统：设备外壳接本地接地极，通常依赖剩余电流保护装置等措施实现故障切断。
  • IT 系统：电源带电部分与地绝缘或经阻抗接地，需配套绝缘监测和故障处理。

重要修正： 不能把“同一设备不能同时接地和接零”当作通用规范结论。TN-C-S 等系统中 PEN 在规定位置分为 PE 和 N 后，PE 与 N 必须按规范布线，分开后不得在下游随意再次连接；PE 不得作为正常工作电流回路。接地与等电位连接的设计必须按当地电气规范和具体系统制式实施。

15. 连续信号和离散信号的本质区别是什么？

答案： 连续时间信号 x(t) 在连续时间轴上定义；离散时间信号 x[n] 只在离散采样时刻定义。数字系统把物理世界的模拟信号经过采样和量化转成有限数据，再由 CPU/MCU 处理。

  • 采样：时间轴离散化。
  • 量化：幅度映射到有限精度等级。
  • 编码：把量化结果表示为二进制数。

采样会受到混叠约束；量化会引入量化误差。连续系统的微分方程在数字控制中常转成差分方程。

flowchart LR
  A[连续模拟信号 x(t)] --> B[采样：时间离散]
  B --> C[量化：幅度离散]
  C --> D[编码：有限位宽]
  D --> E[MCU / DSP 数字处理]

16. 采样频率低于两倍最高频率会发生什么？

答案： 会产生混叠（Aliasing）：高频分量在离散采样后折叠成较低频率的假信号。比如采样频率 fs=1000Hz，900Hz 正弦分量会折叠成 100Hz 的等效低频分量。

防止混叠的主要措施：

  • ADC 前设置模拟抗混叠低通滤波器。
  • 采样频率留有过渡带余量，不要只卡在理论边界。
  • 数字下采样前先做低通滤波。
  • 对 PWM 电流采样等场景，结合开关频率、采样相位和控制带宽设计。

严格的采样重建条件与信号带限假设有关；实际系统要考虑滤波器非理想性和噪声。

17. 电阻式、电容式和电感式传感器分别适合测什么？

答案：

  • 电阻式：应变片、RTD/PT100、电位器，适合应变、温度、位移等。
  • 电容式：通过极板间距、面积或介电常数变化测量位移、液位、压力和接近量；对寄生电容和湿度较敏感。
  • 电感式：通过磁路/电感变化检测金属接近、位移和涡流效应，常用于恶劣环境下的金属目标检测。

选型需考虑量程、灵敏度、线性度、动态响应、温度漂移、安装空间和信号调理电路。

18. 热电偶和 PT100 的原理及优缺点是什么？

答案：

  • 热电偶：利用塞贝克效应，两个不同导体结点温差产生热电动势。优点是量程宽、响应快、探头可做得小；缺点是输出为毫伏级，需要冷端补偿，精度和线性度依型号与测量链而定。
  • PT100：铂电阻在 0℃ 时标称 100Ω，电阻随温度变化。优点是精度和稳定性较好、特性可标准化；缺点是需要激励电流并处理引线电阻、自热和响应时间。

不能把所有热电偶精度概括成固定 ±2℃，也不能把 PT100 精度概括成固定 ±0.1℃；应按等级、温度范围、接线方式和测量电路核对。

19. 测量系统的静态特性和动态特性有什么区别？

答案：

  • 静态特性：输入恒定或缓慢变化时的表现，包括精度、线性度、迟滞、重复性、灵敏度和漂移。
  • 动态特性：输入快速变化时的跟随能力，包括时间常数、响应时间、带宽和超调。

一个温度传感器可以稳态读数很准，但响应速度很慢；两种特性需要分别评估。

20. ±0.5%FS 是什么意思？量程该怎么选？

答案： FS 是 Full Scale（满量程）。若量程为 0–100℃，精度 ±0.5%FS 对应满量程误差约 ±0.5℃，而不是当前读数的 0.5%。若量程为 0–1000℃，则对应 ±5℃。

量程选得过大，满量程误差和分辨率可能不适合小信号测量；选得过小，则可能超量程饱和或损坏。工程上应根据最大/最小测量值、过载能力、精度预算和动态范围选择，常见“留 20–30% 余量”只是经验起点，不是所有测量系统的统一标准。
