▎1000 问全景（问题库）

▎ 基础概念

  1. “人工智能”、“机器学习”、“深度学习”这三个概念之间的关系是什么样的？用一张包含关系图怎么画？

  2. 图灵测试是什么？如果一个AI通过了图灵测试，它真的”理解”了吗？还是只是装得像在理解？

  3. “强AI”和”弱AI”的区别是什么？现在用的ChatGPT、Midjourney属于哪一种？

  4. 人工智能历史上经历了三次”寒冬”和两次”春天”——每次寒冬的触发因素是什么？每次春天又是因为什么突破？

▎ 机器学习基础

  1. 什么是”监督学习”、“无监督学习”、“半监督学习”、“强化学习”？它们的核心区别在于训练时有没有”标签”？

  2. “过拟合”是什么意思？一个模型在训练集上准确率99%、在测试集上只有60%——这个差距说明了什么？

  3. “欠拟合”和”过拟合”的平衡——模型太简单会欠拟合、太复杂会过拟合，中间那个点怎么找到？

  4. 训练集、验证集、测试集——三个集合各有什么用？为什么不能拿测试集来做模型选择？

▎ 深度学习基础

  1. 一个神经网络最基本的组成单元是什么？一个”神经元”在数学上做了什么操作——加权求和+激活函数？

  2. 为什么神经网络需要”激活函数”？如果激活函数是线性的（f(x)=x），再多层也能合并成一层——能理解这个问题吗？

  3. ReLU、Sigmoid、Tanh——三种激活函数各有什么优缺点？为什么ReLU在深度网络里比Sigmoid更常用？

  4. 反向传播（backpropagation）的直觉是什么？链式法则在这里起了什么作用？

▎ 监督学习算法

  1. 线性回归为什么叫”线性”？如果数据不是线性的（比如抛物线形状），线性回归还能用吗？

  2. 逻辑回归（Logistic Regression）名字里带”回归”，但做的是分类任务——它到底回归了什么？

  3. 决策树是怎么做分类的？根节点选哪个特征来分裂——选择标准是什么？

  4. 支持向量机（SVM）的”间隔最大化”是什么意思？为什么它要找离两类数据最远的那条分界线？

  5. k近邻（k-NN）为什么是”懒学习”？训练阶段不需要做什么，预测时反而要大量计算——合理吗？

▎ 模型评估

  1. 准确率（Accuracy）在什么情况下会骗人？一个99%准确率的癌症检测模型，如果发病率只有1%，它可能什么都没检测出来——为什么？

  2. 精确率（Precision）和召回率（Recall）的区别是什么？搜索引擎更关心哪个？

  3. F1分数为什么是精确率和召回率的”调和平均”而不是算术平均？什么时候该用F1而不是单独用P或R？

  4. ROC曲线和AUC——ROC曲线画的是什么？AUC=0.5意味着什么、AUC=1.0又意味着什么？

▎ 优化方法

  1. 梯度下降（Gradient Descent）的直觉是什么？沿着梯度反方向走为什么能找到最小值？

  2. 学习率太大了会怎样？太小了呢？有没有”自适应”的学习率方法？

  3. 随机梯度下降（SGD）和批量梯度下降（Batch GD）的区别是什么？SGD一次只看一个样本就更新参数——这样参数会不会”乱跳”？

  4. 什么是”局部最优”和”全局最优”？在非凸函数的优化里，梯度下降会被困在局部最优吗？

▎ 无监督学习

  1. K-means聚类是怎么工作的？“K”代表什么？为什么需要先确定K？

  2. K-means的”初始质心”怎么选？选不好会怎么样？

  3. 主成分分析（PCA）在做什么？为什么说它”找数据里方差最大的方向”？这个方向和”保留最多信息”有什么关系？

▎ 神经网络架构——CNN

  1. 卷积层（Convolution）在图像上做了什么操作？一个3×3卷积核和一个5×5卷积核的区别是什么？

  2. 池化（Pooling）层有什么用？最大池化和平均池化各自提取了什么特征？

  3. 卷积神经网络为什么比全连接网络更适合处理图像？“平移不变性”和”局部连接”在这起了什么作用？

▎ 神经网络架构——RNN / 序列模型

  1. 循环神经网络（RNN）是怎么处理序列数据的？为什么说它的”隐藏状态”在记忆之前的信息？

  2. RNN的”梯度消失”问题是怎么产生的？为什么长句子RNN记不住开头的信息？

  3. LSTM（长短期记忆网络）的三个门（遗忘门、输入门、输出门）各在控制什么？为什么它能记住远距离的信息？

▎ NLP / 词嵌入基础

  1. Word2Vec是怎么把”单词”变成”向量”的？为什么”国王-男人+女人≈女王”能成立？

▎ 计算机视觉基础

  1. 图像分类任务里，一张224×224的彩色图片在计算机里是几个数？如果输入到神经网络，第一层要处理多少参数？

▎ Transformer 与注意力机制

  1. 注意力机制（Attention）的直觉是什么——“在翻译一句话时，模型不应该平等地看所有词，而是应该关注当前输出位置最相关的输入词”——它的数学表达 Q、K、V 三个矩阵分别代表什么？

  2. Transformer 的”自注意力”（Self-Attention）和 RNN 在处理序列上的本质区别是什么？为什么说 Transformer 是”并行”而 RNN 是”串行”的——这个并行带来了什么好处？

  3. Transformer 里的位置编码（Positional Encoding）为什么需要？既然输入是并行处理的，模型怎么知道哪个词在前、哪个词在后？

▎ 大语言模型（LLM）基础

  1. GPT 的”自回归”（Autoregressive）是什么意思——生成下一个词时，它能看到哪些词？这和 BERT 的”双向”有什么本质不同？

  2. 什么是”涌现能力”（Emergent Abilities）？为什么 7B 的模型不会做算术，70B 的模型突然会了——这个”突然”是哪来的？

  3. 为什么大模型需要”上下文窗口”（context window）的限制？如果一次给它输入 10 万字的对话，为什么它会”忘掉”开头说了什么？

▎ 强化学习基础

  1. 强化学习里的”智能体”（Agent）、“环境”（Environment）、“动作”（Action）、“奖励”（Reward）四个要素是什么关系？AlphaGo 下围棋——每一步落子是 Action，赢了是 Reward（+1），这是一个什么过程？

  2. 强化学习里的”探索”（Exploration）和”利用”（Exploitation）的权衡是什么？一个扫地机器人总是在同一个角落转（利用它已知的最好路径）和去新区域试试（探索）——怎么决定什么时候试新路？

▎ 集成学习（Bagging / Boosting）

  1. 随机森林（Random Forest）是怎么通过”多个弱分类器组合成一个强分类器”的？为什么每棵树只用部分数据和部分特征，结果反而比一棵全数据的决策树好？

  2. XGBoost 和随机森林在”构建多棵树”时的理念有什么不同——一个并行建树再投票（Bagging），一个串行建树、每棵新树纠正前一棵的错（Boosting）？

▎ 生成式模型（GAN / VAE / 扩散模型）

  1. 生成对抗网络（GAN）的”生成器”和”判别器”在玩一个什么游戏？生成器画假画，判别器鉴定真假——为什么这个博弈能训练出能画逼真人脸的生成器？

  2. Stable Diffusion 这类”扩散模型”的原理直觉是什么——从一个全是噪声的图片开始，一步步”去噪”直到变成一张清晰的猫的图片？每一步去掉一点噪声，这个”去噪”过程是谁教给模型的？

▎ 迁移学习与微调

  1. ImageNet 上预训练好的 ResNet 模型，被迁移到”X光胸片分类”任务上——前几层（识别边缘、纹理）不用重学，只需要在最后几层重新训练——为什么前几层的特征是”通用的”？

  2. “全量微调”和”LoRA（低秩适配）“微调的区别是什么？为什么 LoRA 只需要训练参数量 0.1% 的权重就能达到接近全量微调的效果？

▎ 模型可解释性

  1. 深度模型经常被说成”黑箱”——可解释性方法 LIME 和 SHAP 各自怎么解释一个模型为什么把某张图片分类为”猫”？LIME 在图片的局部区域加模糊，看分类结果变化；SHAP 根据每个像素对最终判断的贡献分配”重要性分数”——两个思路有什么不同？

▎ 推荐系统基础

  1. 协同过滤（Collaborative Filtering）和基于内容的推荐（Content-based）的本质区别是什么？Amazon 的”买了这个商品的用户也买了…”是哪种？

  2. 推荐系统里的”冷启动”（Cold Start）问题是什么？一个新用户没有任何行为记录，一个新商品没有任何用户评价——推荐系统怎么给它们推荐？

▎ 目标检测与语义分割

  1. 图像分类、目标检测、语义分割——三个任务的输出分别是什么？分类输出”猫”，检测输出”猫在 (x,y,w,h)“，分割输出”图片里每一个像素属于猫还是背景”——哪一步最难？

  2. YOLO（You Only Look Once）为什么叫这个名字？它把目标检测当成一个”回归问题”——输入一张图，直接输出所有边界框的位置和类别，一步到位，跟 R-CNN 两阶段方法的区别在哪？

▎ 图神经网络（GNN）

  1. 图神经网络在解决什么问题？社交网络里的每个人是一个节点，朋友关系是一条边——如果只给部分节点标注了”高消费用户”，怎么预测其他节点是否高消费？

  2. GNN 的”消息传递”（Message Passing）是什么意思？每个节点收齐邻居的信息，“更新”自己的特征——重复几轮后，相隔两跳的节点也能互相影响吗？

▎ 自监督学习与对比学习

  1. 自监督学习（Self-Supervised Learning）为什么叫”自”监督——数据没有人类标注的标签，模型自己给自己造”伪标签”来学习。在 NLP 里 BERT 的做法是”盖住一些词让模型猜”，这跟”有监督学习”有什么不同？

  2. 对比学习（Contrastive Learning）的核心思想是什么——“让同一张猫的两张不同变换（裁剪、旋转）后的图片在特征空间里靠近，让不同图片远离”？这个”拉近同类、推远异类”的训练目标跟分类的交叉熵损失比，优势在哪？

▎ 模型部署与推理优化

  1. 训练好的 PyTorch 模型要部署到手机或服务器上，为什么要”导出”成 ONNX 或 TensorRT 格式？直接用 PyTorch 的 .pt 文件跑推理不行吗？

  2. 模型量化（Quantization）把 float32 变成 int8 后，模型大小变成原来的四分之一，推理速度大幅提升——但精度为什么几乎不掉？这是因为神经网络对噪声的”鲁棒性”吗？

▎ AI伦理与公平性

  1. 人脸识别系统对不同肤色人群的准确率不同——这个”偏差”来自哪里？是模型的偏见还是训练数据分布不均匀？

  2. 一个银行的贷款审批模型，训练数据里过去批准的大多数贷款给了男性，模型学会把”性别”作为重要特征——怎么检测并消除这个偏见？用”性别”这个敏感属性不能作为输入就能解决吗？

▎ 语音与音频处理基础

  1. 语音识别（ASR）的第一步通常是把声音信号变成频谱图（Mel频谱）——为什么原始波形不好直接用？人耳对频率的感知不是线性的，Mel 刻度就是模拟了这个非线性特性？

  2. 文本到语音（TTS）是怎么让合成的语音听起来不像机器人的？现在的主流 TTS（如 Tacotron、VITS）的核心思路是”从文本到频谱再到波形”——中间的频谱怎么反过来变成声音？

▎ 强化学习深入（Q-Learning / DQN）

  1. Q-Learning 的 Q 值代表什么？“Q(s, a)“——在一个状态 s 下执行动作 a，未来能获得的总回报期望。为什么 Q 值不是一个数而是一张”状态×动作”的表？当状态空间连续（比如机器人关节角度）时，这张表存不下怎么办？

  2. Deep Q-Network（DQN）用神经网络代替了 Q 表——输入是状态，输出是每个动作的 Q 值。那 DQN 怎么解决”用网络当前预测的 Q 值来更新网络自身”这个循环依赖问题？“目标网络”（Target Network）在这做了什么？

  3. Policy Gradient 方法和 Q-Learning 的思维方式本质区别是什么？一个直接学”在每个状态选什么动作最好”，另一个学”每个动作值多少钱”，然后根据值来选——PPO 为什么在实践中比 DQN 更稳定？

▎ RAG（检索增强生成）

  1. RAG 的核心链路是：用户提问 → 把问题转成向量 → 从向量数据库里检索最相关的几段文本 → 把检索到的文本拼到 prompt 里 → LLM 回答。为什么说 RAG 解决了 LLM 的”知识截止日期”和”幻觉”两个问题？它跟直接把大段资料塞进上下文的做法有什么不同？

  2. RAG 里的”分块策略”（chunking）——一段 500 页的 PDF，是按每 256 个字切块、还是按段落切块、还是按语义切块？如果切得太碎，检索回来的片段说了一半的话没有上下文；切得太大，一个块里混合了多个主题。怎么找到中间的平衡点？

▎ AI Agent / 工具使用

  1. 一个”AI Agent”和普通的 LLM 聊天有什么区别？Agent 的核心是”能自己决定调用工具”——比如问天气，Agent 不直接回答，而是决定去调用天气 API——这个”决定调用哪个函数”的行为是什么机制控制的？

  2. ReAct（Reasoning + Acting）模式是怎么工作的？Agent 收到问题后，不是一步给出答案，而是”想一下 → 查一下 → 再想想 → 再查一下”的循环，直到有足够信息才回答——这个”思考-行动-观察”的循环跟人类解决问题的流程有什么相似之处？

▎ 向量数据库与嵌入搜索

  1. 向量数据库存的是什么？不是存原始文本，而是存”文本的语义向量”——“猫追老鼠”和”猫咪在抓耗子”两句话的向量距离很近。那么问题来了：怎么把”语义相似”映射成”向量距离近”？这个映射是谁训练的？

  2. 向量数据库做搜索时的”近似最近邻”（ANN）和传统的”精确最近邻”有什么区别？一个 100 万条向量精确找最近的 10 条，逐条比对太慢——ANN 通过牺牲一点精度（比如只找到 95% 的正确答案）来换取千倍的速度提升，它用了什么数据结构？

▎ 时间序列分析与预测

  1. 时间序列预测跟普通回归预测的本质区别是什么？普通回归假设样本相互独立，但今天的气温和昨天的气温是高度相关的——时间序列预测的核心是捕捉这个”时间依赖结构”。ARIMA 模型怎么通过”自回归”（AR）和”滑动平均”（MA）两种成分来描述时间序列？

  2. LSTM 在时间序列预测里跟传统统计方法（ARIMA、指数平滑）比，有什么不可替代的优势？如果一个任务是预测明天某个化工反应釜的温度——历史数据有 3 年的每小时记录，数据有明显的季节性模式和偶尔的异常波动——LSTM 能比 ARIMA 多抓住什么？

▎ AutoML 与超参数优化

  1. 手动调参的问题在哪？一个 XGBoost 模型有十几个超参数，每个参数连续取值——搜索空间是天文数字。网格搜索（Grid Search）为什么在这个场景下不可行？

  2. 贝叶斯优化（Bayesian Optimization）是怎么用更少的试验次数找到好超参数的？它给每个超参数组合一个”期望分数”和”不确定性”——每次选那些”可能好但不确定”的参数来试，而不是”确定好但已经试过的”。为什么这个策略比随机搜索高效？

▎ 多模态学习（Vision + Language）

  1. CLIP 模型是怎么同时理解图片和文字的？OpenAI 用 4 亿张（图片，文字描述）对来训练——让”一张猫的图片”的向量和”一只橘猫在晒太阳”的文本向量靠近，跟不匹配的图片-文本对远离。训练完后，怎么用 CLIP 做”零样本分类”——给它一张它没见过的品种的狗的照片，它怎么猜出这是”狗”？

  2. 多模态大模型（如 GPT-4V、LLaVA）是怎么实现”看图说话”的？一个典型的做法是把图片切成 patch，用视觉编码器（如 ViT）把每个 patch 转成向量，然后把图像向量序列当 prompt 拼到文本 token 前面——这样 LLM 就能”看到”图片的内容了？这个拼接方式有什么问题？

▎ 知识图谱

  1. 知识图谱的”三元组”（头实体—关系—尾实体）是什么？“北京是中国的首都”三元组化后变成（北京，首都，中国）。知识图谱为什么用这种结构来表示知识——如果用关系数据库的表来存，跟三元组比差在哪？

  2. 知识图谱的”补全”（Knowledge Graph Completion）是在解决什么问题？知识图谱通常是不完整的——如果已知（姚明，妻子，___）缺了尾实体，怎么用已有的三元组推断出缺失的部分？TransE 模型的思路是把每个实体和关系都投影到向量空间，通过”头实体向量+关系向量≈尾实体向量”来预测缺失联系？

▎ 异常检测（Anomaly Detection）

  1. 异常检测的三种类型——点异常（一个数据点偏离全局分布）、上下文异常（某时刻的数值跟它前后时刻比不对）、集体异常（一组数据一起出现但单独看每个都正常）。

  2. 孤立森林（Isolation Forest）检测异常的原理是什么？正常数据点需要很多次分割才能被”孤立”，异常点只需要很少几次分割就能被孤立出来。

▎ 特征工程与数据预处理

  1. 为什么机器学习模型通常需要”特征缩放”？SVM 和 KNN 依赖距离计算，树模型不需要——为什么？

  2. 类别特征怎么变成数值输入？独热编码导致维度暴涨时，目标编码（Target Encoding）有什么风险和怎么处理？

▎ 联邦学习（Federated Learning）

▎ 小样本学习与零样本学习
