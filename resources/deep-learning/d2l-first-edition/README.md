# 《动手学深度学习》第一版（中文）

> 来源：<https://zh-v1.d2l.ai/index.html>  
> 上游项目：<https://github.com/d2l-ai/d2l-zh>  
> 书籍 PDF：<https://zh-v1.d2l.ai/d2l-zh.pdf>

## 同步说明

本目录收录 NotesBook 对《动手学深度学习》第一版中文资源的索引、学习路径与本地化整理。第一版网站是历史版本，内容以 MXNet / Gluon 为主；不要用第二版 PyTorch 内容覆盖它。上游仓库同时承载第二版及项目公共资源，迁移时应锁定第一版对应的历史版本/发布包，并保留原始目录结构、图片、公式、代码与版权声明。

## 内容范围

- 原书正文：绪论、预备知识、线性神经网络、多层感知机、深度学习计算、卷积神经网络、现代卷积神经网络、循环神经网络、现代循环神经网络、注意力机制、优化算法、计算性能、计算机视觉、自然语言处理等章节。
- 代码与实验：MXNet、NDArray、自动求导、Gluon、数据加载、模型训练与预测。
- 配套资源：图片、公式、附录、工具安装说明、代码运行环境和练习。
- 学习沉淀：在本目录新增的中文导读、章节笔记、知识图谱和练习解答应与上游原文分开存放，避免误改原始材料。

## 推荐学习顺序

1. **基础准备**：安装与使用、符号约定、数据操作、数据预处理、线性代数、微积分、自动微分、概率论。
2. **核心模型**：线性回归、Softmax 回归、多层感知机、欠拟合与过拟合、权重衰减、Dropout。
3. **视觉模型**：卷积、填充与步幅、池化、LeNet、AlexNet、VGG、NiN、GoogLeNet、批量归一化、ResNet。
4. **序列模型**：序列模型、文本预处理、语言模型、循环神经网络、GRU、LSTM、深度循环网络、机器翻译与注意力。
5. **训练工程**：优化算法、GPU 计算、分布式训练与性能优化。
6. **应用专题**：目标检测、语义分割、风格迁移、自然语言处理应用。

## 版本与兼容性

- 本目录对应 **第一版（zh-v1）**，不是当前第二版网站。
- 原书代码基于 MXNet / Gluon 生态，部分依赖和数据下载地址可能已经过时；运行时应使用独立虚拟环境，并在章节笔记中记录可复现的依赖版本。
- 建议后续将每章拆分为「原始资料 / 中文精读笔记 / 可运行代码 / 练习与答案 / 参考资料」，不直接改写上游原文。
