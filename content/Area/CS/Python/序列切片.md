# Python 序列切片

原始 Flomo：https://v.flomoapp.com/mine/?memo_id=MjMzNzc5Nzkz

切片是 Python 中用于访问序列（如列表、元组、字符串）中部分元素的技术。通过指定起始索引和结束索引，可以提取序列的一部分。切片的基本语法如下：<br>sequence\[start:stop:step\]

- start：切片的起始索引（包含该索引的元素）。

- stop：切片的结束索引（不包含该索引的元素）。

- step：切片的步长，默认为 1。<br>你可以生成列表的任何子集，甚至可以使用负数索引来从序列的末尾开始切片。切片操作不会修改原始序列，而是返回一个新的序列。
