在 Python 中，设计模式通常被分为三大类（创建型、结构型、行为型），共有 23 种经典模式。由于 Python 具备强大的动态特性（如函数作为一等公民、动态类型、元编程、__new__、鸭子类型等），许多在 Java 或 C++ 中需要复杂结构的设计模式，在 Python 中可以实现得非常优雅、简练。
以下是 Python 实现的全部 23 种经典设计模式的完整指南，划分为三大模块，每个模式都包含核心定义与最精简的 Python 骨架代码。

---

## 一、 创建型模式 (Creational Patterns) - 5种

核心目的：优雅地创建对象，将对象的创建与使用解耦。

## 1. 单例模式 (Singleton)

* 定义：确保一个类只有一个实例，并提供一个全局访问点。
* Python 实现：利用类属性或 __new__ 方法。

```python
class Singleton:
    _instance = None
    def __new__(cls, *args, **kwargs):
        if not cls._instance:
            cls._instance = super().__new__(cls)
        return cls._instance
s1 = Singleton()s2 = Singleton()assert s1 is s2  # 两个变量指向同一内存地址
```
## 2. 简单工厂 / 工厂方法 (Factory Method)

* 定义：定义一个创建对象的接口，让子类决定实例化哪一个类。
* Python 实现：由于 Python 中类可以像变量一样传递，直接使用字典映射或条件判断即可。

```python
class Dog: def speak(self): return "Woof!"class Cat: def speak(self): return "Meow!"
class PetFactory:
    @staticmethod
    def get_pet(pet_type):
        pets = {"dog": Dog, "cat": Cat}
        return pets.get(pet_type, Dog)()
pet = PetFactory.get_pet("cat")
print(pet.speak())  # Meow!
```
## 3. 抽象工厂 (Abstract Factory)

* 定义：提供一个创建一系列相关或相互依赖对象的接口，而无需指定它们具体的类。
```python
class LuxuryCar: def drive(self): return "Smooth ride"class EconomyCar: def drive(self): return "Cheap ride"class LuxurySUV: def offroad(self): return "Luxury offroad"class EconomySUV: def offroad(self): return "Basic offroad"
class VehicleFactory:  # 抽象工厂接口
    def create_car(self): pass
    def create_suv(self): pass
class LuxuryFactory(VehicleFactory):
    def create_car(self): return LuxuryCar()
    def create_suv(self): return LuxurySUV()
```
## 4. 建造者模式 (Builder)

* 定义：将一个复杂对象的构建与其表示分离，使得同样的构建过程可以创建不同的表示。
```python
class Burger:
    def __init__(self):
        self.bun = None
        self.patty = None
class BurgerBuilder:
    def __init__(self): self.burger = Burger()
    def add_bun(self, bun): self.burger.bun = bun; return self
    def add_patty(self, patty): self.burger.patty = patty; return self
    def build(self): return self.burger
burger = BurgerBuilder().add_bun("Wheat").add_patty("Beef").build()
```
## 5. 原型模式 (Prototype)

* 定义：用原型实例指定创建对象的种类，并且通过拷贝这些原型创建新的对象。
* Python 实现：直接使用标准库的 copy.deepcopy。

```python
class Prototype:
    def __init__(self, value): self.value = value
    def clone(self): return copy.deepcopy(self)

obj1 = Prototype([1, 2, 3])
obj2 = obj1.clone()
assert obj1 is not obj2 and obj1.value == obj2.value
```

## 二、 结构型模式 (Structural Patterns) - 7种

核心目的：处理类或对象的组合，形成更大的结构。

## 6. 适配器模式 (Adapter)

* 定义：将一个类的接口转换成客户希望的另外一个接口，使得原本由于接口不兼容而不能一起工作的那些类可以一起工作。
```python
class Target:
    def request(self): return "Standard response"
class Adaptee:
    def specific_request(self): return "esnopser laiceps" # 反向的
class Adapter(Target):
    def __init__(self, adaptee): self.adaptee = adaptee
    def request(self): return self.adaptee.specific_request()[::-1] # 转换为标准形式
```
## 7. 桥接模式 (Bridge)

* 定义：将抽象部分与实现部分分离，使它们都可以独立地变化。

```python
class Red: def get_color(self): return "Red"class Blue: def get_color(self): return "Blue"
class Shape:
    def __init__(self, color_implementor): self.color = color_implementor
    def draw(self): pass
class Circle(Shape):
    def draw(self): return f"Circle painted {self.color.get_color()}"
circle = Circle(Red())
```
## 8. 组合模式 (Composite)

* 定义：将对象组合成树形结构以表示“部分-整体”的层次结构，使得用户对单个对象和组合对象的使用具有一致性。

```python
class Component:
    def execute(self): pass
class Leaf(Component):
    def execute(self): return "Leaf"
class Composite(Component):
    def __init__(self): self.children = []
    def add(self, child): self.children.append(child)
    def execute(self): return [c.execute() for c in self.children]
```
## 9. 装饰器模式 (Decorator)

* 定义：动态地给一个对象添加一些额外的职责。
* Python 实现：除了常规的类包装，Python 内置的 @decorator 语法糖是其最自然的体现。

```python
def make_bold(func):
    def wrapper(): return f"<b>{func()}</b>"
    return wrapper

@make_bolddef greet(): return "Hello"
print(greet())  # <b>Hello</b>
```
## 10. 外观模式 (Facade)

* 定义：为子系统中的一组接口提供一个一致的界面，此模式定义了一个高层接口，这个接口使得这一子系统更加容易使用。

```python
class CPU: def start(self): return "CPU standard"class Memory: def load(self): return "Memory load"
class ComputerFacade: # 外观类封装复杂的子系统调用
    def __init__(self):
        self.cpu = CPU()
        self.memory = Memory()
    def start(self):
        return f"{self.cpu.start()} -> {self.memory.load()}"
```
## 11. 享元模式 (Flyweight)

* 定义：运用共享技术有效地支持大量细粒度的对象（节约内存）。

```python
class TreeType: # 共享的享元
    def __init__(self, name, color):
        self.name = name
        self.color = color
class TreeFactory:
    _types = {}
    @classmethod
    def get_type(cls, name, color):
        if (name, color) not in cls._types:
            cls._types[(name, color)] = TreeType(name, color)
        return cls._types[(name, color)]
```
## 12. 代理模式 (Proxy)

* 定义：为其他对象提供一种代理以控制对这个对象的访问。

```python
class RealSubject:
    def request(self): return "Real request"
class Proxy:
    def __init__(self, real_subject): self._real = real_subject
    def request(self):
        # 可以在此处执行权限检查、缓存、日志等
        return f"Proxy log -> {self._real.request()}"
```

## 三、 行为型模式 (Behavioral Patterns) - 11种

核心目的：关注对象之间的通信、职责分配与算法交互。

## 13. 责任链模式 (Chain of Responsibility)

* 定义：避免请求发送者与接收者耦合在一起，让多个对象都有可能接收请求，将这些对象连接成一条链，并且沿着这条链传递请求。

```python
class Handler:
    def __init__(self, successor=None): self.successor = successor
    def handle(self, request): pass
class ConcreteHandlerA(Handler):
    def handle(self, request):
        if request == "A": return "Handled by A"
        elif self.successor: return self.successor.handle(request)
```
## 14. 命令模式 (Command)

* 定义：将一个请求封装为一个对象，从而使你可用不同的请求对客户进行参数化。

```python
class Light:
    def turn_on(self): return "Light ON"
class TurnOnCommand:
    def __init__(self, light): self.light = light
    def execute(self): return self.light.turn_on()
class RemoteControl:
    def submit(self, command): return command.execute()
```
## 15. 解释器模式 (Interpreter)

* 定义：给定一个语言，定义它的文法的一种表示，并定义一个解释器，这个解释器使用该表示来解释语言中的句子。

```python
class Number:
    def __init__(self, value): self.value = value
    def interpret(self): return self.value
class Add:
    def __init__(self, left, right): self.left = left; self.right = right
    def interpret(self): return self.left.interpret() + self.right.interpret()
# 解释 1 + 2expression = Add(Number(1), Number(2))
print(expression.interpret()) # 3
```
## 16. 迭代器模式 (Iterator)

* 定义：提供一种方法顺序访问一个聚合对象中各个元素，而又不需暴露该对象的内部表示。
* Python 实现：Python 的 __iter__ 和 __next__ 是内置的迭代器协议。

```python
class MyCollection:
    def __init__(self, data): self.data = data
    def __iter__(self):
        self.index = 0
        return self
    def __next__(self):
        if self.index < len(self.data):
            val = self.data[self.index]; self.index += 1; return val
        raise StopIteration
```
## 17. 中介者模式 (Mediator)

* 定义：用一个中介对象来封装一系列的对象交互，中介者使各对象不需要显式地相互引用。

```python
class ChatRoom: # 中介者
    def display_message(self, user, message):
        print(f"[{user.name}]: {message}")
class User:
    def __init__(self, name, chat_mediator):
        self.name = name; self.mediator = chat_mediator
    def send(self, message): self.mediator.display_message(self, message)
```
## 18. 备忘录模式 (Memento)

* 定义：在不破坏封装性的前提下，捕获一个对象的内部状态，并在该对象之外保存这个状态，以便以后可见将对象恢复到原先保存的状态。

```python
class Memento:
    def __init__(self, state): self._state = state
class Originator: # 原发器
    def __init__(self): self.state = ""
    def save(self): return Memento(self.state)
    def restore(self, memento): self.state = memento._state
```
## 19. 观察者模式 (Observer)

* 定义：定义对象间的一种一对多的依赖关系，当一个对象的状态发生改变时，所有依赖于它的对象都得到通知并被自动更新。
```python
class Subject:
    def __init__(self): self._observers = []
    def attach(self, observer): self._observers.append(observer)
    def notify(self, message):
        for obs in self._observers: obs.update(message)
class Observer:
    def update(self, message): print(f"Received: {message}")
```
## 20. 状态模式 (State)

* 定义：允许一个对象在其内部状态改变时改变它的行为。对象看起来似乎修改了它的类。
  
```python
class State: def handle(self): pass
class RedState(State): def handle(self): return "Red Light - Stop"class GreenState(State): def handle(self): return "Green Light - Go"
class TrafficLight:
    def __init__(self): self.state = RedState()
    def change(self): return self.state.handle()
```
## 21. 策略模式 (Strategy)

* 定义：定义一系列的算法，把它们一个个封装起来，并且使它们可相互替换。
* Python 实现：由于 Python 支持一等公民函数，直接传入不同的函数通常就是最好的策略模式实现。

```python
def discount_strategy_a(price): return price * 0.9def discount_strategy_b(price): return price - 20
class Order:
    def __init__(self, price, strategy):
        self.price = price; self.strategy = strategy
    def calculate_total(self): return self.strategy(self.price)
order = Order(100, discount_strategy_a)
```
## 22. 模板方法模式 (Template Method)

* 定义：定义一个操作中的算法的骨架，而将一些步骤延迟到子类中。

```python
class AbstractWorker:
    def template_method(self): # 定义了骨架
        self.get_up()
        self.work()
    def get_up(self): print("Wake up")
    def work(self): pass # 留给子类实现
class Developer(AbstractWorker):
    def work(self): print("Write Python code")
```
## 23. 访问者模式 (Visitor)

* 定义：封装一些作用于某种数据结构中的各元素的操作，它可以在不改变数据结构的前提下定义作用于这些元素的新操作。

```python
class Node:
    def accept(self, visitor): pass
class CityNode(Node):
    def accept(self, visitor): visitor.visit_city(self)
class ExportVisitor: # 访问者
    def visit_city(self, city): print("Exporting city data to XML")
```
