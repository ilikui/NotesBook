**专栏⑳·第2篇：感知层——摄像头、毫米波、激光雷达、超声波**

▎ **四种传感器的分工**

1. 摄像头：2D 视觉，信息最丰富（车道线 / 交通灯 / 目标识别），但怕雨雾逆光、无精确测距
2. 毫米波雷达：测距测速（多普勒效应），全天候，但分辨率低、分不清目标类型
3. 激光雷达：3D 点云，精度高，但贵、怕大雨、远距离点云稀疏
4. 超声波：近距离（泊车），便宜，低速可用

▎ **物理原理（一句话）**

- 摄像头：被动光，像素 → 特征
- 毫米波：77GHz 电磁波，FMCW 调频测距 + 多普勒测速
- 激光雷达：TOF（飞行时间）或 FMCW，每秒几十万点
- 超声波：声波 TOF，3-5m

▎ **布置（融合的前提）**

- 前视（挡风玻璃后）：主摄像头 \+ 长距雷达
- 四角：角雷达（盲区监测）
- 车顶 / 前格栅：激光雷达（L4 方案）
- 布置决定视野，视野决定融合难度

▎ **关键参数与选型**

- 摄像头：分辨率 / 帧率 / FOV / 动态范围（HDR）
- 毫米波：探测距离 / 角度分辨率 / 速度分辨率
- 激光：线数（16/32/64/128）/ FOV / 点频 / 精度
- 选型看场景：高速看远用毫米波 \+ 前视，城市场景看全用激光 \+ 环视

▎ **三个坑**

1. 摄像头怕雨雾逆光——L2+ 必须有毫米波兜底，单摄像头方案恶劣天气直接失效
2. 激光雷达远距离点云稀疏，目标检测退化——和摄像头融合才能互补
3. 传感器标定是融合的地基——内参外参标错，融合全错

▎ **一句话**：感知层是「互补矩阵」——摄像头管是什么、毫米波管多快多远、激光雷达管多精确、超声波管多近；没有全能传感器，融合的前提是每个传感器先标定对。
