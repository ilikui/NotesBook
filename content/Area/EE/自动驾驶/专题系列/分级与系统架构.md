**专栏⑳·第1篇：分级与系统架构——L0-L5、感知-决策-执行、中央计算演进**

▎ **分级（SAE L0-L5）**

- L0-L2：辅助驾驶，人负责——量产主流
- L3：有条件自动驾驶，系统负责、人随时接管—— **责任转移的分水岭**，出了事故谁负责
- L4：高度自动驾驶，限定场景（Robotaxi / 港口 / 矿区）
- L5：完全自动驾驶，无限制
- 现实：量产 L2/L2+ 是主流，L3 试点，L4 跑限定场景

▎ **系统架构：感知-决策-执行三环**

1. 感知：摄像头 / 毫米波 / 激光雷达 / 超声波 → 环境模型（车道线、障碍物、目标）
2. 决策：预测（别人要干嘛）→ 规划（全局路径 → 行为决策 → 局部轨迹）
3. 执行：线控转向 / 制动 / 驱动 → 车辆运动

▎ **硬件架构演进（接区域架构专题）**

- 分布式（50-100 个 ECU）→ 域集中（自动驾驶域控 / 座舱域控 / 车身域控）→ 中央计算 + 区域控制器（Zonal）
- 中央计算：大算力 SoC（Orin / Thor / 8155 / 8295），区域控制器管 IO 和配电

▎ **软件架构（Adaptive AUTOSAR）**

- Classic AUTOSAR 管实时控制（MCU 层），Adaptive 管高算力应用（SoC 层）
- 自动驾驶软件栈：OS（Linux / QNX）→ 中间件（DDS / SOME-IP）→ 算法模块（感知 / 融合 / 规划）

▎ **一句话**：自动驾驶 = 感知\-决策\-执行三环 \+ 算力底座；分级看责任转移（L3 是分水岭），架构从分布式演进到中央计算——你 AUTOSAR 的经验在 Classic 层依然值钱，区域架构转型最缺的正是老 ECU 工程师。
