**专栏⑳·第4篇：决策规划——预测、行为决策、轨迹规划**

▎ **在整条链路的位置**<br>
感知回答了「现在世界什么样」，决策规划要回答「接下来怎么动」——预测别人、决定自己、规划路径。

▎ **三个层级**

1. 全局路径规划：起点到终点（导航地图层面）——A\* / Dijkstra / RRT
2. 行为决策：下一步动作（跟车 / 变道 / 超车 / 停车 / 让行）——状态机 / 规则 / 学习
3. 局部轨迹规划：未来几秒的具体轨迹（位置 / 速度 / 曲率随时间）——Frenet 坐标系 + 采样 / 优化

▎ **预测模块（决策的前提）**

- 预测其他参与者的意图：车道保持 / 变道 / 转弯
- 方法：运动学模型外推、行为模型（意图分类）、交互博弈
- 难点：预测不准是常态——决策要鲁棒，留安全余量

▎ **关键约束**

- 安全：碰撞避免（安全距离 / 紧急制动）
- 舒适：加速度 / jerk（加加速度）限制
- 法规：交规约束（车道 / 限速 / 信号灯）

▎ **三个坑**

1. 只规划不预测：把别人当静止物体——高速场景直接出事；预测是决策的前置
2. 轨迹优化只看安全不看舒适：乘客晕车——jerk 限制要进约束
3. 场景切换拍脑袋：规则冲突（让行 vs 抢行）——要有仲裁优先级

▎ **一句话**：决策规划分三层——全局路径（去哪）、行为决策（怎么走）、局部轨迹（怎么动）；预测是决策的前置、舒适是硬约束、规则冲突要有仲裁。
