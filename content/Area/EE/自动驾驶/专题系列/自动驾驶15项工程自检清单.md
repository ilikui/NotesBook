# 专栏⑳·第10篇：自动驾驶 15 项自检清单——上车前逐项打勾

原始 Flomo：https://v.flomoapp.com/mine/?memo_id=MjUyMTU2MDQz

**专栏⑳·第10篇：自动驾驶 15 项自检清单——上车前逐项打勾**

▎ **感知层（3 项）**

1. 传感器选型覆盖场景了吗？——高速看远（毫米波 \+ 前视）、城区看全（激光 \+ 环视）、泊车（超声波）
2. 每个传感器的内参 / 外参标定验证过吗？（标错 = 融合全错）
3. 恶劣天气兜底方案在不在？——摄像头失效时毫米波 / 雷达能不能独立撑住

▎ **融合层（2 项）**<br>
4\. 所有传感器时间基准统一了吗？（StbM / gPTP，时间不同步 = 高速目标错位）<br>
5\. 目标关联 / 状态估计的虚警漏检权衡记录过吗？（确认阈值按场景调过吗）

▎ **决策规划层（2 项）**<br>
6\. 预测模块在链路里吗？（只规划不预测 = 把别人当静止物）<br>
7\. 轨迹约束含舒适性吗？（jerk 限制，别让乘客晕车）

▎ **执行层（2 项）**<br>
8\. 执行器延迟补偿进决策了吗？（转向 50-100ms、制动 100-150ms）<br>
9\. 冗余是异构的吗？失效安全策略测过组合失效吗？

▎ **底座层（2 项）**<br>
10\. 通信带宽按峰值算过吗？（8 路摄像头原始数据 GB 级，压缩 / 边缘处理了吗）<br>
11\. 计算平台按 TOPS/W 选型了吗？安全关键功能有没有独立 MCU 兜底？

▎ **安全层（2 项）**<br>
12\. SecOC 的密钥进 HSM 了吗？新鲜度值防回滚吗？<br>
13\. OTA 有 A/B 分区回滚吗？（变砖是底线事故）

▎ **系统层（2 项）**<br>
14\. ASIL 等级按 HARA 定过吗？安全机制（看门狗 / ECC）运行时在自检吗？<br>
15\. 整个链路有没有端到端时间预算？（感知 → 决策 → 执行，每级延迟量过吗）

▎ **判定**

- 14-15 项 ✅：系统可上车
- 10-13 项 ✅：能跑，但某层在漏（看哪层失分多）
- 10 项以下 ✅：先补最弱层，别整体上量

▎ **一句话**：15 项对应六层（感知 3 / 融合 2 / 决策 2 / 执行 2 / 底座 2 / 安全 2 / 系统 2）——失分最集中的层就是下一轮迭代的重点；自动驾驶没有单点英雄，只有链条。
