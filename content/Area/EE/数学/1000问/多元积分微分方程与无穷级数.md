# 考研数学1000问：多元积分、常微分方程与无穷级数

## 一、多元积分

### Q1. 二重积分与定积分有什么关系？它在计算什么？

**答案：** 一重定积分沿一维区间累积函数值；二重积分在二维区域上累积函数值：

~~~~text
∬_D f(x,y) dA
~~~~

当 f(x,y)=1 时，结果是区域 D 的面积；当 f 是高度/密度时，可计算体积、质量或总量。二重积分是对二维区域进行细分、求和并取极限。

### Q2. 二重积分怎样化为累次积分？先积 x 还是先积 y？

**答案：** 先描述积分区域 D，再按选定顺序写出边界。若区域可表示为 a≤x≤b、g1(x)≤y≤g2(x)，则：

~~~~text
∬_D f(x,y)dA = ∫[a,b] ( ∫[g1(x),g2(x)] f(x,y)dy ) dx
~~~~

也可以反过来先对 x 积分。选择顺序时，优先让区域边界和被积函数简单；若区域不适合单一顺序，可拆成多个子区域。上下限必须由图形/不等式推导，不能只凭记忆套公式。

### Q3. 极坐标变换为什么要乘 r？

**答案：** 极坐标变换 x=r cosθ、y=r sinθ 的 Jacobian 行列式绝对值为 r，因此面积元：

~~~~text
dA = dxdy = r dr dθ
~~~~

直觉上，半径 r 处一个小扇形的弧长约为 r dθ，径向宽度为 dr，面积约为 r dr dθ。漏掉 r 会系统性算错积分。

### Q4. 三重积分的柱坐标和球坐标体积元是什么？

**答案：**
- 柱坐标：x=r cosθ，y=r sinθ，z=z，体积元 dV=r dr dθ dz。
- 球坐标（θ 为方位角、φ 为从正 z 轴量起的极角）：x=ρ sinφ cosθ，y=ρ sinφ sinθ，z=ρ cosφ，体积元 dV=ρ² sinφ dρ dφ dθ。

不同教材对球坐标角度符号定义可能不同，写积分前先确认角度定义和取值范围。

## 二、常微分方程

### Q5. 一阶线性方程 y'+p(x)y=q(x) 的积分因子怎样推导？

**答案：** 目标是把左侧变成一个乘积的导数。设积分因子 μ(x)，希望：

~~~~text
(μy)' = μq
~~~~

展开得 μ'y+μy'=μq。与原方程比较，需要 μ'/μ=p(x)，因此：

~~~~text
μ(x)=exp(∫p(x)dx)
~~~~

于是：

~~~~text
y = (1/μ(x)) * [ ∫ μ(x)q(x)dx + C ]
~~~~

积分因子不是凭空记忆的技巧，而是通过乘一个函数把方程改写为全导数。

### Q6. 可分离变量方程怎样求解？为什么积分常数不需要两边各写一个？

**答案：** 若 y'=g(x)h(y)，且 h(y) 在所讨论区间不为 0，可分离为：

~~~~text
dy/h(y) = g(x) dx
~~~~

两边积分后得到一个关系式，合并成一个任意常数 C 即可。若把两边分别写常数 C1、C2，最终只会出现差值 C2−C1，仍然是一个任意常数。

要特别检查 h(y)=0 的常值解；分离变量时除以 h(y) 可能把这些解丢掉。

### Q7. 二阶常系数齐次线性方程的特征根决定什么？

**答案：** 对：

~~~~text
a y'' + b y' + c y = 0
~~~~

设 y=e^(rx)，得到特征方程 ar²+br+c=0。

- 两个不同实根 r1、r2：y=C1e^(r1x)+C2e^(r2x)。
- 重根 r：y=(C1+C2x)e^(rx)。
- 共轭复根 α±iβ：y=e^(αx)(C1cosβx+C2sinβx)。

根的实部决定指数增长/衰减，虚部决定振荡频率。这也是分析线性系统稳定性和阻尼特性的基础。

### Q8. 非齐次方程的特解怎样猜？什么时候需要乘 x？

**答案：** 对常系数线性方程，右端为多项式、指数或正弦/余弦时，可按相同函数族构造待定系数特解。若猜测形式与齐次解重复（共振），需要乘 x 的适当幂次，直到与齐次解线性无关。

例：若右端为 e^(rx)，而 r 已是特征根，直接猜 Ae^(rx) 会落入齐次解空间，代入后无法确定 A；此时需改猜 Axe^(rx)，重根时可能需要 x²。

## 三、无穷级数

### Q9. 为什么通项趋于 0 仍不能保证级数收敛？

**答案：** 级数 Σa_n 收敛的必要条件是 a_n→0，但不是充分条件。调和级数 Σ1/n 的通项趋于 0，却仍发散，因为每一组分块的和不会趋于 0。

判断级数收敛必须研究部分和序列，而不是只看单项大小。

### Q10. 正项级数的比较、比值和根值判别法怎么用？为什么 ρ=1 判断不了？

**答案：**
- 比较判别：与已知收敛/发散的正项级数比较大小。
- 比值判别：计算 lim a_(n+1)/a_n；小于 1 收敛，大于 1 发散。
- 根值判别：计算 lim (a_n)^(1/n)；小于 1 收敛，大于 1 发散。

若比值或根值极限等于 1，判别法不提供结论；例如 Σ1/n 与 Σ1/n² 的相关比值极限都为 1，但一个发散、一个收敛。此时要换用比较、积分、凝聚或其他判别法。

### Q11. 幂级数的收敛半径是什么？为什么端点要单独判断？

**答案：** 对幂级数 Σa_n(x−x0)^n，存在收敛半径 R，使 |x−x0|<R 时绝对收敛，|x−x0|>R 时发散。R 可用比值法或根值法求得。

在 |x−x0|=R 的两个端点，结论不由收敛半径决定，可能收敛也可能发散，必须分别代入原级数检查。端点行为可能不同，例如一个端点条件收敛、另一个端点发散。

## 工程连接

- 二重积分可用于计算二维传感器区域上的总量或概率密度积分。
- 一阶线性微分方程常用于 RC 电路、电机电流和一阶热模型。
- 二阶常系数方程可分析 RLC 电路、机械振动和控制系统阻尼。
- 幂级数与 Taylor 展开可用于局部数值近似，但必须检查收敛区间和误差。
