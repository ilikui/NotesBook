# 考研数学1000问：线性代数基础、矩阵运算与线性方程组

## 一、基础概念与矩阵运算

### Q1. 向量和标量最本质的区别是什么？

**答案：** 标量是一个数值，描述大小；向量是向量空间中的元素，具有可加和数乘结构。几何上，二维/三维向量可表示方向和大小；但在线性代数中，向量也可以是多项式、函数或一组数据，不一定是空间箭头。

例如：
- 温度 25°C 是标量。
- 平面位移 (3,4) 是二维向量。
- 长度为 n 的传感器特征列表也可视为 R^n 中的向量。

向量是否成立，关键在于其集合和加法、数乘是否满足向量空间公理。

### Q2. 矩阵为什么是二维的？它和向量有什么关系？

**答案：** m×n 矩阵是 m 行 n 列的数表，可以表示从 n 维输入到 m 维输出的线性变换。矩阵的行列数描述输入、输出维度，不是说矩阵本身一定代表“二维平面”。

矩阵乘向量：

~~~~text
A (n维输入) -> m维输出
y = A x
~~~~

例如，一个 3×2 矩阵把二维向量映射成三维向量；在信号处理中，矩阵也可表示多通道线性混合或坐标变换。

### Q3. 零向量和零矩阵为什么要单独定义？

**答案：** 零向量是向量空间加法的单位元，满足 v+0=v；零矩阵是矩阵加法的单位元，满足 A+0=A。它们虽然元素都为 0，但所属集合和维度不同。

零向量通常是一个向量空间中的唯一加法单位元；m×n 零矩阵则有明确的矩阵维度。在线性方程组 Ax=0 中，零向量是齐次方程的必然解。

### Q4. 矩阵乘法为什么不是逐元素相乘？

**答案：** 矩阵乘法表达线性变换的复合和向量分量的线性组合。若 A 是 m×n，B 是 n×p，则 AB 是 m×p，其元素：

~~~~text
(AB)_ij = Σ(k=1..n) A_ik * B_kj
~~~~

逐元素乘法（Hadamard product）是另一种运算，要求两个矩阵形状相同，表达对应位置相乘，不表示一般线性变换复合。

### Q5. 为什么 AB 通常不等于 BA？举一个直观例子。

**答案：** 矩阵乘法表示先后执行变换，变换顺序通常会改变结果。例如先旋转再缩放，与先缩放再旋转，在非均匀缩放时一般不同；先投影再旋转与先旋转再投影也不同。

因此 AB 与 BA 的差异体现了操作顺序。只有在特定条件下（如某些对角矩阵、同一矩阵的幂或可交换矩阵）才会相等。矩阵乘法不满足交换律，但满足结合律和分配律。

### Q6. 矩阵的逆为什么不是 1/A？什么条件下可逆？

**答案：** 矩阵是线性变换，逆矩阵 A^-1 表示把变换撤销，使 A^-1A=AA^-1=I；它不是对每个元素取倒数。

对于 n×n 方阵，以下条件等价：
- det(A) 不等于 0；
- rank(A)=n；
- 列向量线性无关；
- 对任意 b，Ax=b 有唯一解；
- A 的线性变换是一一且满射。

非方阵通常没有双侧逆，但可能有左逆、右逆或 Moore-Penrose 伪逆。

### Q7. 转置在几何和计算上有什么意义？

**答案：** 转置 A^T 把行列互换。它把线性映射的表示转为其对偶映射，也与内积、投影、最小二乘和协方差矩阵密切相关。

重要性质：
- (A^T)^T=A
- (A+B)^T=A^T+B^T
- (AB)^T=B^T A^T
- 若 A 可逆，则 (A^-1)^T=(A^T)^-1

在工程中，转置常用于把样本按行/列组织、构造正规方程和计算投影。

## 二、线性方程组与矩阵分解

### Q8. 高斯消元法本质上在做什么？

**答案：** 高斯消元通过初等行变换，把线性方程组的增广矩阵化为阶梯形或行最简形，从而识别主元、自由变量和矛盾行，得到解的结构。

允许的初等行变换：
1. 交换两行；
2. 某行乘非零常数；
3. 某行加上另一行的倍数。

这些操作不改变方程组的解集。消元是对方程组做等价变换，而不是随意改变未知量。

### Q9. 线性方程组无解、唯一解、无穷多解分别对应什么？

**答案：** 对 Ax=b，设 A 的秩为 r，增广矩阵 [A|b] 的秩为 r'，未知数个数为 n：

- r 不等于 r'：无解（出现矛盾行）。
- r=r'=n：唯一解。
- r=r'<n：无穷多解，有 n-r 个自由变量。

这就是 Rouché–Capelli 定理的秩判据。齐次方程 Ax=0 一定至少有零解；当 rank(A)<n 时还有非零解。

### Q10. LU 分解为什么有用？它比重复高斯消元好在哪？

**答案：** LU 分解把矩阵写成 L（下三角）与 U（上三角）的乘积，常见形式为 PA=LU（带行交换矩阵 P）。求多个右端项 Ax=b 时，可先分解一次，再分别解 Ly=Pb 与 Ux=y。

它的优势是复用分解结果、便于求解多个线性系统；但数值稳定性需要考虑主元选取，实践中常用部分主元 LU。若矩阵病态或结构特殊，也可能选择 QR、Cholesky 或迭代法。

## 三、向量空间、基与线性变换

### Q11. 什么是向量空间？数轴算不算？

**答案：** 向量空间是一个集合，定义了向量加法和标量乘法，并满足封闭性、交换律、结合律、零向量、加法逆元和数乘分配等公理。

实数集合 R 在通常加法和实数数乘下是一个一维向量空间，所以数轴算向量空间。R²、R³、n 维实向量、次数受限的多项式集合和满足条件的矩阵集合也可以构成向量空间。

### Q12. 基是什么？为什么同一个空间有无数种基？

**答案：** 基是一组线性无关且能张成整个向量空间的向量。任意向量都能被唯一表示为基向量的线性组合。

R² 的标准基是 (1,0)、(0,1)，但 (1,1)、(1,-1) 也能构成另一组基。只要向量组线性无关且张成整个空间，它就是一组基。不同基只是用不同坐标描述同一个向量。

### Q13. 线性相关与线性无关为什么重要？

**答案：** 向量组线性相关，表示其中至少一个向量可由其他向量线性组合得到，存在冗余；线性无关表示不存在这种冗余。

基必须线性无关，因为只有这样坐标表示才唯一。矩阵列向量是否线性无关决定列秩、可逆性和线性方程组是否存在自由变量。

### Q14. 维数为什么与基的选择无关？

**答案：** 有限维向量空间中，任意一组基包含相同数量的向量，这个数量定义为空间维数。不同基改变坐标系，但不改变空间本身的自由度。

例如 R³ 的任何基都包含 3 个线性无关向量；若只有 2 个向量无法张成整个 R³，若有 4 个向量则必然线性相关。

### Q15. 线性变换为什么要满足 T(u+v)=T(u)+T(v) 和 T(cv)=cT(v)？

**答案：** 这两条性质确保变换保留向量空间的线性结构：加法关系和数乘关系在变换后仍成立。满足这两条性质的映射称为线性变换。

若 T(v)=Av，则：
- T(u+v)=A(u+v)=Au+Av；
- T(cv)=A(cv)=cAv。

平移变换 T(x)=Ax+b（b 非零）通常不是线性变换，而是仿射变换，因为 T(0)=b 不等于 0。

### Q16. 矩阵怎样代表线性变换？矩阵乘向量在做什么？

**答案：** 选定输入空间和输出空间的基后，线性变换 T 可由矩阵 A 表示。矩阵的每一列是输入基向量经 T 变换后的坐标。

因此 Ax 是把输入向量按坐标展开，再对变换后的基向量做相同线性组合。矩阵不是“神秘的数字表”，而是某个线性映射在指定基下的坐标表示。

### Q17. Kernel 和 Image 怎么理解？

**答案：**
- Kernel（核）：所有被映射到零向量的输入集合，即 ker(T)={v | T(v)=0}。它表示变换会完全抹掉哪些方向。
- Image（像/值域）：所有可能输出构成的集合，即 im(T)={T(v)}。它表示变换能到达哪些输出方向。

秩—零化度定理：dim(ker T)+dim(im T)=dim(输入空间)。对矩阵 A，rank(A) 是像空间维数，nullity(A) 是零空间维数。
