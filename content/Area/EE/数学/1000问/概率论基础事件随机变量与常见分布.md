# 考研数学1000问：概率事件、随机变量与常见分布

## 一、随机事件与概率

### Q1. 古典概型的“等可能”假设到底意味着什么？硬币对称就一定公平吗？

**答案：** 古典概型要求样本空间有限，且每个基本结果被认为具有相同概率。若有 N 个等可能基本结果，事件 A 包含其中 k 个，则 P(A)=k/N。

硬币几何对称只是公平性的直觉依据，不是严格证明；真实抛掷还受初始姿态、角速度、落地方式、弹跳和表面影响。数学模型中的“公平硬币”是对 P(正)=P(反)=1/2 的假设，是否适用于现实要靠实验数据检验。

### Q2. 条件概率 P(B|A) 为什么像“缩小样本空间”？

**答案：** 在 P(A)>0 时：

~~~~text
P(B|A) = P(A∩B) / P(A)
~~~~

知道 A 已发生后，只在 A 这个条件范围内重新归一化概率；A 内同时发生 B 的部分就是 A∩B。因此可以直观理解为把样本空间缩小到 A，但要记住概率仍然是对条件事件 A 内的结果重新归一化。

### Q3. 全概率公式和贝叶斯公式是什么关系？

**答案：** 若 B1,...,Bn 构成完备事件组（互斥且并集为全集），则：

~~~~text
P(A) = Σ_i P(A|B_i)P(B_i)
~~~~

这是全概率公式：把不同原因路径的概率加总，求结果 A 的总概率。

贝叶斯公式则反向更新原因概率：

~~~~text
P(B_j|A) = P(A|B_j)P(B_j) / P(A)
~~~~

可理解为“先验 × 似然 / 证据”得到后验。全概率常用于计算分母 P(A)，贝叶斯再由结果反推原因。

### Q4. 事件独立和互斥能同时成立吗？

**答案：** 若 A、B 互斥，则 P(A∩B)=0；若独立，则 P(A∩B)=P(A)P(B)。二者同时成立要求 P(A)P(B)=0，也就是至少一个事件概率为 0。

因此，对两个概率都大于 0 的事件，互斥与独立不能同时成立。互斥表示不能同时发生；独立表示一个事件是否发生不改变另一个事件的概率。

### Q5. 三个人独立破译密码，成功概率分别为 0.8、0.7、0.6，至少一人成功的概率是多少？

**答案：** 先算“全部失败”的概率。独立条件下：

~~~~text
P(all fail) = (1-0.8)(1-0.7)(1-0.6)
            = 0.2 * 0.3 * 0.4
            = 0.024
P(at least one succeeds) = 1 - 0.024 = 0.976
~~~~

“至少一个”通常用对立事件更简单；如果不独立，不能直接把失败概率相乘，必须知道联合概率结构。

### Q6. n 个球放入 N 个盒子，至少一个盒子空的概率怎么算？

**答案：** 若每个球独立且等概率地进入 N 个盒子，总分配数为 N^n。用容斥原理计算“所有盒子都不空”的分配数：

~~~~text
P(all nonempty) = (1/N^n) * Σ(k=0..N) (-1)^k C(N,k)(N-k)^n
P(at least one empty) = 1 - P(all nonempty)
~~~~

若 n<N，根据抽屉原理必有空盒，概率为 1。若 n≥N，上式可计算；也可用第二类 Stirling 数表示为 N! S(n,N)/N^n。

## 二、一维随机变量与常见分布

### Q7. 分布函数 F(x)=P(X≤x) 为什么必须右连续？

**答案：** 分布函数定义为 F(x)=P(X≤x)。当 x_n 从右侧单调下降到 x 时，事件 {X≤x_n} 逐渐缩小到 {X≤x}，由概率测度对递减事件列的连续性（概率有限）可得 F(x_n)→F(x)，所以 CDF 右连续。

此外，CDF 单调不减，且 x→−∞ 时趋于 0，x→+∞ 时趋于 1。这些性质可用于判断一个函数是否可能是分布函数。

### Q8. 离散随机变量为什么要求概率之和为 1？

**答案：** 离散随机变量所有可能取值构成互斥且完备的事件集合。它必然取其中一个值，因此这些取值的概率之和必须等于 1：

~~~~text
Σ_i P(X=x_i)=1
~~~~

若和小于 1，说明漏掉了某些可能结果；若大于 1，说明事件重叠或概率定义不一致。

### Q9. 连续随机变量在某个点的概率为什么是 0？概率为 0 是否等于不可能？

**答案：** 若 X 有概率密度 f(x)，则单点概率：

~~~~text
P(X=a) = ∫[a,a] f(x)dx = 0
~~~~

连续分布的概率分配在区间上，而不是某个单点上。因此 P(X=a)=0 不表示 a 在逻辑上不可能取到；它表示单点在连续样本空间中概率测度为零。比如连续均匀分布在 [0,1] 上，P(X=0.5)=0，但 0.5 仍是可能取值。

### Q10. 0-1、二项、泊松和几何分布分别描述什么场景？

**答案：**
- Bernoulli( p )：一次试验只有成功/失败两种结果，成功概率 p。
- Binomial(n,p)：n 次独立 Bernoulli 试验中的成功次数。
- Poisson(λ)：固定区间内稀有事件发生次数，均值和方差均为 λ。
- Geometric(p)：独立重复试验中，直到第一次成功所需的试验次数（不同教材也有从失败次数开始的定义，需看约定）。

选分布时先明确随机变量代表“单次结果、固定次数成功数、单位区间事件数，还是等待时间/次数”。

### Q11. 泊松分布为什么能近似二项分布？

**答案：** 当 n 很大、p 很小且 λ=np 保持有限时，Binomial(n,p) 的概率质量函数可近似为 Poisson(λ)：

~~~~text
P(X=k) ≈ exp(-λ) * λ^k / k!
~~~~

直觉是大量独立试验中每次成功概率很低，但总期望成功数固定，最终成功次数近似服从泊松分布。近似质量取决于 n、p；不能只凭“事件少”就使用泊松。

### Q12. 数学期望和方差分别表示什么？

**答案：** 数学期望 E[X] 是随机变量的概率加权平均，描述长期重复试验的中心位置；方差 Var(X)=E[(X−E[X])²] 描述围绕期望的离散程度。

若 X、Y 独立，则 E[XY]=E[X]E[Y]；一般情况下不能这么拆。方差满足 Var(X)=E[X²]−(E[X])²，且 Var(aX+b)=a²Var(X)。

### Q13. 协方差和相关系数有什么区别？

**答案：** 协方差 Cov(X,Y)=E[(X−EX)(Y−EY)] 描述两个变量是否倾向于同向或反向变化，但受量纲和尺度影响。

相关系数：

~~~~text
rho = Cov(X,Y) / (sigma_X * sigma_Y)
~~~~

把协方差标准化到 [-1,1]，表示线性相关方向和强度。相关系数为 0 只表示不相关，不代表独立；联合正态分布下不相关才可推出独立。

## 三、大数定律与中心极限定理

### Q14. 大数定律说什么？为什么样本均值会趋近总体期望？

**答案：** 在满足相应独立性、同分布或其他条件时，随着样本量增大，样本均值会以概率意义或几乎必然意义趋近总体期望。这解释了大量重复试验下频率和平均值的稳定性。

大数定律不表示每增加一个样本，平均值都更接近真实期望；有限样本仍会波动，也不保证样本中不存在偏差或数据分布发生变化。

### Q15. 中心极限定理和大数定律有什么不同？

**答案：** 大数定律说明样本均值趋近总体期望；中心极限定理进一步描述标准化样本均值的分布形状，在适当条件下趋近标准正态分布：

~~~~text
Z = (X_bar - mu) / (sigma / sqrt(n))
~~~~

它让我们在样本量足够大时近似计算均值相关概率。CLT 不是说原始数据一定服从正态分布，也不是说任意小样本都可以直接套正态近似。

### Q16. 为什么样本均值的标准误差是 σ/√n？

**答案：** 若 X1,...,Xn 独立同分布，方差均为 σ²，则：

~~~~text
Var(X_bar) = Var((1/n)ΣX_i) = (1/n²)ΣVar(X_i)=σ²/n
~~~~

所以样本均值的标准差（标准误差）为 σ/√n。注意是除以 √n，而不是除以 n。若样本相关、方差不相同或存在聚类结构，公式需要调整。
