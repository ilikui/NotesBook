# MATLAB与Simulink10000问：基础语法、矩阵运算与建模

本篇迁移 MATLAB/Simulink 题库首批 12 个问题，覆盖矩阵表达、索引、向量化、脚本函数、函数句柄、数据容器、绘图、矩阵运算、线性方程求解和 Simulink 求解器。

## 1. MATLAB 为什么叫“矩阵实验室”？标量和矩阵有什么关系？

**答案：** MATLAB 名称来自 Matrix Laboratory。矩阵是 MATLAB 的核心数据组织形式：标量可看成 1×1 矩阵，行向量和列向量是特殊矩阵，多维数组则把这种组织推广到更多维度。现代 MATLAB 还支持 table、timetable、cell、struct、string、对象等类型，不能把所有数据都简化为普通矩阵。

## 2. MATLAB 中方括号里的空格、逗号和分号分别表示什么？

**答案：** 在矩阵构造表达式中，空格或逗号通常分隔同一行的列元素；分号分隔不同行。例如：

~~~~matlab
A = [1 2 3; 4 5 6];
~~~~

得到 2×3 矩阵。使用逗号代替空格可提高可读性，但要注意表达式中函数参数逗号与矩阵构造语法的上下文。

## 3. 冒号表达式 1:2:10 会生成什么？

**答案：** 冒号表达式 start:step:end 按指定步长生成等间隔序列。1:2:10 得到 [1 3 5 7 9]，因为下一个值 11 已超过终点 10。浮点步长可能出现舍入误差；需要精确样本数时可用 linspace。

## 4. MATLAB 为什么从 1 开始索引，而 C 从 0 开始？

**答案：** MATLAB 的 1-based indexing 更贴近数学中的第一个元素编号；C 的 0-based indexing 便于用“基地址 + 下标×元素大小”计算偏移。两种设计各有历史和生态原因。跨语言传递数组时必须明确下标约定，避免 off-by-one 错误。

## 5. 为什么 MATLAB 常建议向量化？它一定比 for 循环快吗？

**答案：** 向量化把一组元素运算交给 MATLAB 内部优化实现，可能利用高效底层库、减少解释器层面的循环开销。但向量化也可能产生大型临时数组，增加内存占用；现代 MATLAB 的 JIT 已优化许多循环，因此应基于实际数据规模和 profile 测量，而不是盲目改写。

## 6. Script 和 Function 有什么区别？

**答案：** Script 在调用者工作区中执行，通常会读取/修改当前 workspace 的变量；Function 有独立的局部工作区，通过输入和输出参数传递数据，利于封装、测试和复用。大型工程应优先把可复用逻辑写成函数，减少脚本对 base workspace 的隐式依赖。

## 7. 匿名函数 @(x) x.^2+1 是什么？它和函数句柄有什么关系？

**答案：** 匿名函数用表达式定义一个轻量函数，赋值后得到函数句柄，可作为参数传给优化、绘图或数值求解函数。例如：

~~~~matlab
f = @(x) x.^2 + 1;
y = f([1 2 3]);
~~~~

点运算符 .^ 表示逐元素乘方；若使用矩阵幂 ^，则遵循线性代数中的矩阵幂规则，要求矩阵方阵并满足相应定义。

## 8. Cell 数组和 Struct 分别适合什么场景？

**答案：** Cell 数组适合按位置存储不同类型或不同长度的数据；Struct 适合按字段名称组织具有语义关系的数据。例如多种长度的传感器记录可放在 cell 中；一个 ECU 配置对象可用 struct 的 voltage、temperature、status 等字段表达。

## 9. plot、hold on 和 hold off 分别做什么？

**答案：** plot 绘制二维曲线；默认新绘图可能替换当前坐标区内容。hold on 保持当前图形，使后续绘图叠加在同一坐标区；hold off 恢复默认替换行为。多条曲线叠加时应添加 legend、坐标标签和单位，避免图形无法解释。

## 10. A*B 与 A.*B 有什么区别？

**答案：** A*B 是矩阵乘法，要求 A 的列数等于 B 的行数；A.*B 是逐元素乘法，要求数组尺寸兼容（支持隐式扩展的版本/场景也要注意维度规则）。例如两个同尺寸信号向量逐点相乘应使用 .*；线性变换和矩阵模型通常使用 *。

## 11. 为什么求解 A*x=b 推荐用 A\b，而不是 inv(A)*b？

**答案：** A\b 会调用数值线性代数求解器，按矩阵结构选择适当分解，通常比显式计算逆矩阵更高效、稳定，也更节省内存。inv(A)*b 不仅多做了求逆工作，还可能放大数值误差。若 A 病态，应进一步检查条件数、模型误差和正则化需求。

## 12. Simulink 连续求解器和离散求解器有什么区别？

**答案：** 连续求解器用于求解连续时间状态方程，常见有变步长 ode45/ode23 等；离散求解器按固定或配置采样时间更新离散状态，适合数字控制器和离散系统。混合模型可同时包含连续与离散模块，求解器配置要匹配模型采样时间、零交叉、实时执行目标和精度需求。
