# 电气工程10000问：自动控制、电机拖动与矢量控制

本篇迁移电气工程 10000 问第四批 9 道问答，覆盖开环/闭环、传递函数、PID、稳定性、根轨迹、双闭环调速、FOC、异步电机转差率和电机转矩—转速特性。

## 31. 开环控制和闭环控制的本质区别是什么？

**答案：** 开环控制没有把输出反馈到控制器，控制器按预设指令执行；闭环控制测量输出，与目标值比较得到误差，再据此调整输入。

闭环可抑制扰动和模型误差，但会引入稳定性、噪声和反馈延迟问题。开环不等于“不自动”，而是没有输出反馈校正。

~~~~mermaid
flowchart LR
  A[目标值] --> B[开环控制器]
  B --> C[被控对象]
  C --> D[输出]
  E[目标值] --> F[比较器]
  G[反馈传感器] --> F
  F --> H[闭环控制器]
  H --> I[被控对象]
  I --> J[输出]
  J --> G
~~~~

## 32. 传递函数是什么？为什么用拉普拉斯变换？

**答案：** 对线性时不变系统，在零初始条件下，传递函数定义为 G(s)=Y(s)/U(s)。拉普拉斯变换把时域微分方程转为 s 域代数关系，便于分析串联、并联、反馈、极点、零点和稳定性。

传递函数是输入输出关系，不直接保留所有内部状态信息；多输入多输出和内部状态分析常用状态空间模型。

## 33. PID 中 P、I、D 各起什么作用？为什么要做抗饱和和微分滤波？

**答案：**

- P：根据当前误差产生控制量，通常提高响应速度，但单独使用可能存在稳态误差。
- I：累计历史误差，可消除某些稳态误差；执行器饱和时可能产生积分 windup。
- D：利用误差变化趋势提供阻尼，可能减小超调；但对测量噪声敏感。

实际控制器常对积分项做限幅/反算抗饱和，对微分项做低通滤波，并考虑采样周期、输出限幅和执行器速率限制。

## 34. 控制系统的稳定性是什么意思？极点怎样判断稳定？

**答案：** 对连续时间线性时不变系统，渐近稳定要求闭环极点位于复平面左半平面。实部为负的模态随时间衰减；实部为正则发散。若极点在虚轴上，需进一步判断重数和系统结构：简单虚轴极点可能对应边界稳定/持续振荡，重复虚轴极点通常不稳定。

对离散时间系统，稳定条件是闭环极点位于 z 平面的单位圆内，而不是左半平面。非线性系统还需用 Lyapunov 等方法分析，不能只看传递函数极点。

## 35. 根轨迹法如何判断系统稳定性？

**答案：** 根轨迹描述开环增益 K 变化时闭环特征根在 s 平面中的运动。若某一 K 下所有闭环极点在左半平面，连续 LTI 闭环系统渐近稳定；轨迹穿越虚轴的位置可用于求临界增益和振荡频率。

根轨迹还可帮助理解阻尼比、超调和响应速度，但实际设计还需检查增益/相位裕度、时延、饱和和未建模动态。

## 36. 直流调速为什么采用电流内环、速度外环？

**答案：** 电流与电磁转矩直接相关，电流环负责快速控制转矩并提供限流；速度环根据转速误差生成电流给定，负责较慢的速度跟踪和负载扰动抑制。

通常先整定内环，再整定外环。内环带宽应高于外环，但“快 5–10 倍”只是常见设计经验，最终要按对象模型、采样周期、延迟和稳定裕度计算。

~~~~mermaid
flowchart LR
  A[速度给定] --> B[速度调节器 ASR]
  B --> C[电流给定]
  C --> D[电流调节器 ACR]
  D --> E[变流器 / PWM]
  E --> F[电机]
  F --> G[速度反馈]
  F --> H[电流反馈]
  G --> B
  H --> D
~~~~

## 37. FOC 矢量控制为什么把电流分解成 Id 和 Iq？

**答案：** FOC 通过 Clarke/Park 坐标变换，把三相电流映射到与磁场/转子位置相关的旋转 dq 坐标系，使交流量在稳态下变成较容易调节的近似直流量。控制目标是让磁链相关分量和转矩相关分量在选定坐标系下尽可能解耦。

对表贴式 PMSM，Id 常用于磁链/弱磁控制，Iq 与转矩密切相关；对内嵌式 PMSM 和异步电机，电流分量与转矩/磁链关系更复杂，不能把“Id 只管磁通、Iq 只管转矩”不加条件地推广到所有电机。

~~~~mermaid
flowchart LR
  A[三相电流 Ia Ib Ic] --> B[Clarke]
  B --> C[αβ 静止坐标]
  C --> D[Park：转子角度 θ]
  D --> E[dq 电流 Id / Iq]
  E --> F[d轴 / q轴电流控制]
  F --> G[逆变换与 PWM]
  G --> H[电机]
~~~~

## 38. 异步电机的转差率是什么？为什么正常电动运行需要转差？

**答案：** 同步转速 n₁=60f/p（p 为极对数），转差率 s=(n₁−n)/n₁。异步电机依靠旋转磁场与转子之间的相对运动，在转子中感应电流并产生电磁转矩；若转子完全追上同步磁场，理想情况下感应电势趋近于零，无法维持电动转矩。

电动运行通常 0<s<1；超同步运行时可能进入发电状态，具体还要看转矩方向和能量流向。

## 39. 直流、异步和同步电机的转矩—转速特性有何区别？

**答案：**

- 他励直流电机：在一定磁通和工作范围内，转速随负载转矩增加而近似线性下降。
- 异步电机：转矩随转差增加先上升，达到最大转矩后下降；稳定运行通常位于最大转矩前的区域。
- 同步电机：稳态转速由电源频率和极对数决定，负载变化主要改变功角；超过稳定极限可能失步。

真实曲线受电机参数、控制方式、供电和热限制影响，不能只凭简化曲线完成电机选型。

~~~~mermaid
flowchart TD
  A[电机类型] --> B[直流：近似线性下降]
  A --> C[异步：转矩随转差先升后降]
  A --> D[同步：频率决定转速，过载可能失步]
~~~~
