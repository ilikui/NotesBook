# 电气工程10000问：信号分析、智能电网、PLC与新能源

本篇迁移电气工程 10000 问第五批 8 道问答，覆盖傅里叶变换、智能电网、光伏 MPPT、PLC 扫描、梯形图、电动汽车充电、晶闸管整流和组合/时序逻辑。

## 40. 傅里叶变换在做什么？为什么能把时域信号变成频域信号？

**答案：** 傅里叶变换把信号表示为不同频率正弦/复指数分量的组合，频谱描述各频率成分的幅度和相位。时域看信号随时间如何变化，频域看信号由哪些频率组成，是同一信号的两种表示。

工程用途包括频谱分析、滤波、振动诊断、通信和系统频率响应。FFT 是计算离散傅里叶变换的高效算法，并不等同于连续傅里叶变换本身。

## 41. 智能电网与传统电网的核心差异是什么？

**答案：** 智能电网在电力网络上叠加传感、通信、计算和控制能力，使电网更可观测、可调度和可恢复。

- 传统电网：以集中发电和单向供电为主，用户通常作为负荷。
- 智能电网：支持分布式电源、储能、需求响应、智能计量和配电自动化。
- 新能源和电动汽车增加了电力流和负荷的不确定性，推动电网从被动供电转向双向互动和灵活调度。

智能电网不是简单“所有用户都能向电网卖电”，还依赖并网标准、保护控制、计量结算和市场机制。

## 42. 光伏系统为什么需要 MPPT？常见算法有哪些？

**答案：** 光伏组件的最大功率点随光照、温度和负载变化。MPPT 通过控制 DC-DC 变换器占空比改变组件看到的等效负载，使工作点接近最大功率点。

- 扰动观察法（P&O）：扰动工作点并观察功率变化，简单但可能在 MPP 附近振荡。
- 增量电导法：利用 dP/dV=0 的条件判断工作点位于 MPP 左侧还是右侧。
- 恒压法：用经验电压比例估算 MPP，结构简单但精度有限。

光照增强通常提高可用电流和功率；温度升高通常使开路电压下降。具体曲线和 MPP 位置需结合组件参数与环境条件计算。

  A[光伏组件 V/I 测量] --> B[计算功率 P=V×I]
  B --> C[MPPT 算法]
  C --> D[调整 DC-DC 占空比]
  D --> E[改变组件等效负载]
  E --> A
~~~~

## 43. PLC 的扫描周期通常包含哪些阶段？所有 PLC 都只能循环扫描吗？

**答案：** 典型 PLC 循环扫描包括读取输入映像、执行用户程序、更新输出映像，并穿插通信和诊断服务。输入映像使程序在一个扫描周期内看到一致的输入快照，输出通常在周期末统一更新。

PLC 不等于只能扫描：现代 PLC 也可能支持周期任务、事件任务、中断任务、高速计数和运动控制任务。扫描周期带来可预测性，但输入变化到输出响应会有一个或多个任务周期的延迟。

## 44. 梯形图常开/常闭触点和自锁电路怎样理解？

**答案：** 梯形图触点是对输入映像或内部位的逻辑判断，不是实际机械触点本身：

- 常开触点：对应位为 TRUE 时逻辑导通。
- 常闭触点：对应位为 FALSE 时逻辑导通。
- 自锁：输出置位后，用自身状态维持运行，直到停止条件或复位逻辑解除。

电机启停控制中，启动按钮产生瞬时命令，运行状态需要保持；自锁逻辑把瞬时输入转成持续状态。实际电机控制还必须有过载、急停、安全继电器和硬件互锁，不能只依赖 PLC 程序。

~~~~mermaid
flowchart LR
  A[启动按钮] --> B[运行保持逻辑]
  C[运行状态反馈] --> B
  D[停止 / 急停 / 过载] --> E[复位或断开]
  B --> F[接触器输出]
  E --> F
~~~~

## 45. 交流充电和直流快充有什么本质区别？

**答案：** 交流充电桩主要提供交流电源和通信控制，车载充电机 OBC 完成 AC/DC 转换；直流充电桩在桩内完成大功率 AC/DC 变换，向车辆电池系统提供受控直流，车辆的电池管理系统仍负责电压、电流、温度和安全边界控制。

直流快充通常能提供更高功率，但实际充电速度由桩功率、车辆电池电压平台、BMS 限流、温度、SOC 和充电曲线共同决定。800V 平台在相同功率下可降低电流和线损，但不意味着所有车辆都能自动获得更快充电。

## 46. 不控整流和可控整流有什么区别？SCR 能做什么？

**答案：** 不控整流通常使用二极管，导通时机由电压极性决定；可控整流使用晶闸管 SCR，在正向偏置条件下还需要门极触发，触发角 α 可改变平均输出电压。

对理想三相/单相全控桥等不同拓扑，输出电压公式不同；常见连续电流全控桥模型可出现 Ud 与 cosα 相关的关系，但不能把一个公式套用到所有整流电路。SCR 是半控器件：可控导通，通常依靠电流降到维持电流以下关断。

## 47. 组合逻辑和时序逻辑有什么区别？

**答案：**

- 组合逻辑：输出只由当前输入决定，典型为加法器、译码器和多路选择器。
- 时序逻辑：输出还取决于内部状态，通常包含触发器/锁存器，典型为寄存器、计数器和状态机。

同步数字系统通常由寄存器保存状态，寄存器之间的组合逻辑计算下一状态和输出。时钟沿触发状态更新，建立/保持时间和时钟偏斜会影响可靠性。

~~~~mermaid
flowchart LR
  A[当前输入] --> B[组合逻辑]
  C[当前状态寄存器] --> B
  B --> D[下一状态]
  D --> E[时钟触发器]
  E --> C
~~~~
