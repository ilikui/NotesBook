# 电气工程10000问：继电保护、电驱、逆变与电机调速

本篇迁移电气工程 10000 问第六批 6 道问答，补充继电保护四性、电动汽车电驱系统、PWM 逆变、Buck/Boost、直流电机调速和步进电机定位。

## 48. 继电保护“四性”是什么？速动性和选择性为什么存在张力？

**答案：**

- 选择性：只切除故障区段，尽量不影响健康设备。
- 速动性：尽快切除故障，降低设备损伤并维持系统稳定。
- 灵敏性：对保护范围内的故障能够可靠响应。
- 可靠性：该动作时不拒动，不该动作时不误动。

速动性和选择性可能冲突：若所有保护都无延时动作，上下级保护可能同时跳闸；若一味等待上下级配合，故障切除又会变慢。常见方法是主保护快速切除本区故障，后备保护通过时间/范围配合提供兜底。

**边界：** 距离保护、电流保护和差动保护的配合逻辑不同，不能把“保护线路 80%”或某个固定延时作为所有电网的通用整定值。

## 49. 电动汽车电驱系统由哪些部分组成？为什么电机控制器很关键？

**答案：** 典型电驱总成包括驱动电机、电机控制器/逆变器和减速器（部分集成差速器）。整车三电通常指电池、电机和电控；OBC、DC-DC 和 BMS 也是重要高压系统组成部分。

电机控制器负责把电池直流电变成电机所需的交流电压/频率/相位，并执行电流/转矩控制、能量回收、过流/过压/过温保护和故障诊断。它对动力响应、效率和安全性影响很大，但电池、BMS、热管理、机械传动和整车控制同样关键。

IGBT 与 SiC MOSFET 各有成本、开关损耗和电压等级优势；800V 平台不意味着“必须使用 SiC”，具体由效率、成本、开关频率、热设计和供应链决定。

## 50. PWM 逆变器如何把直流变成交流？为什么波形不是理想正弦？

**答案：** 逆变器通过功率开关器件按 PWM 规律切换直流母线电压。以 SPWM 为例，用正弦调制波与高频三角载波比较，产生脉宽随正弦变化的开关脉冲；电机绕组电感或输出滤波器抑制高频分量，使基波电流接近正弦。

输出仍包含开关频率及其边带谐波，死区时间、器件压降和非线性也会引入低次谐波。可用 THD 等指标评估波形质量。提高开关频率通常有利于滤波，但会增加开关损耗和 EMI，必须折中。

## 51. Buck 和 Boost 变换器为什么能调节直流电压？

**答案：** 两者通过开关管、电感和电容进行能量周期性存储与释放。

- Buck 降压：理想连续电流模式下，Vout≈D×Vin。
- Boost 升压：理想连续电流模式下，Vout≈Vin/(1−D)。

D 是开关占空比。真实电路还存在 MOSFET 导通电阻、二极管压降、电感铜损、开关损耗、寄生参数和控制环路限制；Boost 的 D 不可能无限接近 1 而仍维持理想公式。

~~~~mermaid
flowchart TD
  A[直流输入] --> B[开关管 PWM]
  B --> C[电感储能 / 释能]
  C --> D[二极管或同步整流]
  D --> E[输出电容滤波]
  E --> F[受控直流输出]
  F --> G[反馈采样]
  G --> B
~~~~

## 52. 直流电机调压调速和调磁调速有什么区别？

**答案：** 他励直流电机转速近似满足：

~~~~text
n = (U - Ia × Ra) / (Ce × Φ)
~~~~

- 调压调速：改变电枢电压 U，常用于额定转速以下调速；在磁通近似不变时，通常表现为恒转矩调速区。
- 调磁调速：减小励磁磁通 Φ 可提高转速，通常用于额定转速以上的弱磁区；转矩能力会下降，近似进入恒功率区。

实际范围受电枢电流、换向、热限制、机械强度和控制器约束。不能把“调压永远只往下、调磁永远只往上”当成不考虑四象限运行的完整结论。

## 53. 步进电机为什么可以开环定位？它会不会丢步？

**答案：** 步进电机在驱动器按序励磁时，转子倾向于移动到对应稳定位置；在不失步的条件下，脉冲数与累计步数有确定关系，因此可开环估算角度。

但它并非绝对不会丢步。负载转矩过大、加速度过高、启动频率超出能力、共振或供电不足都可能导致转子跟不上指令。微步驱动能提高指令分辨率和平滑度，但微步位置不等于同等精度的绝对机械定位；高可靠定位可加编码器闭环。

~~~~mermaid
flowchart LR
  A[脉冲 / 方向命令] --> B[步进驱动器]
  B --> C[相电流励磁序列]
  C --> D[转子按步距角运动]
  D --> E[机械负载]
  E --> F{转矩 / 加速度是否超限？}
  F -->|否| G[脉冲数对应位置]
  F -->|是| H[失步 / 位置误差]
~~~~
