# 车载通信1000问：LIN、SDIO、信号完整性与车载以太网

本篇迁移通信协议系列第三批 12 道问答，并保留 Flomo 原始 15 项上车自检清单。重点覆盖 LIN、SDIO、信号完整性和车载以太网。具体电气参数、时序和诊断服务以对应协议版本、PHY/MCU 数据手册和 OEM 网络规范为准。

## 27. LIN 为什么基于 UART？它和普通 UART 点对点通信有什么不同？

**答案：** LIN 在数据帧编码上借用了 UART 的异步串行特性，但物理层通过 LIN 收发器转换成单线车载总线电平，并增加 Sync Break、Sync Field、PID 和校验等协议机制。普通 UART 通常是点对点 TX/RX；LIN 是主从式网络，由主节点按调度表发出 Header，从节点按 PID 响应。

LIN 不是“只要 UART 就能跑”：MCU 还需处理 Break 检测、同步场、校验、调度和唤醒睡眠状态。

## 28. LIN 帧的组成是什么？PID 为什么有校验位？

**答案：** 典型 LIN 帧包含：

1. Break：足够长的显性低电平，标识新帧开始。
2. Break Delimiter：结束 Break。
3. Sync：通常为 0x55，帮助从节点同步波特率。
4. Protected Identifier（PID）：6 位帧 ID 加 2 位奇偶校验。
5. Data：1–8 字节数据。
6. Checksum：经典校验或增强校验。

PID 奇偶校验可帮助检测标识符传输错误；诊断帧使用特定 ID。经典/增强校验的适用范围和例外应按 LIN 版本及诊断帧定义确认。

## 29. LIN Schedule Table 为什么由主节点控制？

**答案：** LIN 从节点不主动竞争总线，主节点按 Schedule Table 决定何时发送哪个 Header，从节点只在匹配 PID 后响应。调度表把报文周期、优先级和网络负载显式化，降低仲裁复杂度并支持低成本节点。

不同调度表可用于正常运行、诊断和低功耗场景。调度周期要考虑信号更新率、总线利用率和响应延迟。

## 30. SDIO 和 SPI 哪个更适合高速外设？

**答案：** SPI 接线简单、控制器普遍、调试容易，适合中低速外设和简单存储器；SDIO 可提供 1-bit/4-bit 等数据线模式，适合 SD 卡、eMMC 相关接口和部分 Wi-Fi 模块，吞吐能力通常高于传统 SPI 配置。

接口选择还要看 MCU 是否有 SDIO 控制器、DMA 支持、驱动成熟度、引脚资源和外设兼容性。不能只凭接口理论带宽决定。

## 31. SD 卡初始化时为什么要发送至少 74 个时钟？ACMD41 前为什么要 CMD55？

**答案：** 上电后 SD 卡需要时钟稳定和初始化时间；主机通常先提供规定数量的时钟，再进入命令初始化流程。ACMD41 属于 Application Specific Command，需先发送 CMD55 设置应用命令前缀，再发送 ACMD41 请求卡初始化/电压协商。

常见流程包含 CMD0、CMD8（按卡类型/版本条件）、CMD55+ACMD41、读取 CID/CSD、分配 RCA、选卡和切换总线宽度。命令支持、响应类型和初始化时序要按 SD 规范及卡规格核对。

## 32. SD 卡、eMMC 和 SDIO Wi-Fi 模块的区别是什么？

**答案：**

- SD 卡：可拆卸存储介质，常用块读写命令访问。
- eMMC：焊接在板上的嵌入式存储器，内部集成 Flash 管理控制器。
- SDIO Wi-Fi：通过 SDIO 接口访问通信外设寄存器和数据通道，不是普通块存储设备。

它们共享部分接口/命令体系，但设备类型、驱动模型和后续协议路径不同。

## 33. 什么时候必须把 PCB 走线当作传输线？

**答案：** 关键因素不是单纯看时钟频率，而是走线传播延迟与信号上升/下降时间的相对关系。边沿越快，越容易出现阻抗不连续反射；即使时钟频率不高，快速边沿也可能需要传输线分析。

“走线长度超过上升沿对应长度的 1/6”是常见工程经验规则，不是严格物理边界。应根据传播速度、边沿时间、驱动阻抗、负载和拓扑判断。

## 34. 反射、终端电阻和阻抗匹配是什么关系？

**答案：** 信号到达阻抗不连续处时会产生反射，表现为过冲、下冲和振铃，可能造成阈值多次穿越和误码。终端匹配让负载阻抗接近传输线特征阻抗，降低反射。

常见参考阻抗：CAN/RS-485 总线常见 120Ω 差分终端；USB 高速差分约 90Ω；车载以太网差分约 100Ω。实际端接位置和拓扑必须按接口规范设计，不能把某个阻值套用到所有接口。

## 35. 串扰为什么会发生？3W 原则和连续回流路径有什么用？

**答案：** 相邻走线之间存在电容和电感耦合，一条线的快速变化可能在另一条线上感应出干扰。增加间距、减少平行长度、控制层叠和保持连续参考平面可以降低串扰。

3W 原则（线间距约为线宽的三倍）是布线经验，不保证所有串扰指标达标。高速差分对还需控制差分间距、长度匹配、参考平面和连接器过渡。

## 36. 为什么高速车载通信要关注共模电压和隔离？

**答案：** 差分接收器允许一定共模电压范围；若两端地电位差或外部干扰使共模电压超出器件规格，可能导致通信错误甚至损坏收发器。长线、跨区域供电和强干扰环境下可评估隔离收发器、数字隔离器、隔离电源和浪涌保护。

隔离不能替代正确的屏蔽、接地和等电位设计；隔离器件还要检查 CMTI、隔离耐压、传播延迟和安全要求。

## 37. 100BASE-T1 为什么只用一对双绞线就能全双工通信？

**答案：** 100BASE-T1 面向车载单对双绞线物理层，通过专用 PHY 技术在同一对线上同时发送和接收，并采用回波/串扰抵消等机制。它与普通 100BASE-TX 的双绞线数量和物理接口不同，不能直接把普通 RJ45 网线插到车载 T1 PHY 上。

车载以太网通常通过交换机形成星型或菊花链等拓扑，具体由网络架构和交换机端口决定。

## 38. SOME/IP、DoIP、AVB/TSN 分别解决什么问题？

**答案：**

- SOME/IP：车载面向服务通信，支持方法调用、事件通知、字段和服务发现。
- DoIP：把诊断通信承载在 IP 网络上，常用于以太网诊断。
- AVB/TSN：提供时间同步、流量整形和调度等机制，改善音视频和关键数据流的时延可控性。

它们处于不同协议层次/功能域，不能互相替代。SOME/IP 服务发现失败时，应抓包检查 OfferService/FindService、组播、VLAN、防火墙和 Service/Instance/Event ID 配置。

## 上车前通信自检清单（15 项）

以下项目是工程检查起点，具体阈值不能脱离器件手册和网络规范使用：

| 组别 | 检查项 | 核验方法 |
|---|---|---|
| 物理层 | UART 波特率误差 | 示波器测 bit 宽度，核对 MCU/对端时钟误差预算 |
| 物理层 | SPI 速率余量 | 按最差电压/温度/负载验证时序与波形 |
| 物理层 | I2C 上拉电阻 | 按总线电容、上升时间和灌电流能力计算 |
| 物理层 | RS-485 终端电阻 | 按总线拓扑在两端端接，测量等效阻抗 |
| 协议实现 | SPI CPOL/CPHA | 对照从设备时序图确认模式与位序 |
| 协议实现 | I2C Clock Stretching | 确认控制器支持与超时配置 |
| 协议实现 | RS-485 DE 时序 | 等待发送完成再切换方向 |
| 协议实现 | Modbus RTU 帧间隔 | 按波特率计算字符时间并验证帧边界 |
| 驱动数据 | 环形缓冲区溢出 | 压测峰值流量和消费者延迟 |
| 驱动数据 | SPI Flash 命令流程 | 写使能、页边界、BUSY 轮询、掉电恢复 |
| 驱动数据 | EEPROM 跨页写入 | 按页拆分并验证写周期完成 |
| 驱动数据 | SENT 数据合理性 | 检查捕获时钟、CRC 和物理范围 |
| 系统集成 | USB 枚举 | 检查描述符、端点、超时和中断处理 |
| 系统集成 | USB 热插拔恢复 | 重新枚举后清理端点与缓存状态 |
| 系统集成 | 协议选型 | 按距离、速率、拓扑、成本、实时性和可靠性评估 |
