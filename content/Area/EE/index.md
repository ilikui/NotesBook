# 电子与嵌入式（EE）

本领域覆盖电路基础、C/C++、计算机系统、MCU、实时操作系统、驱动开发、测试与汽车电子。建议沿着“基础原理 → 编程与系统 → 嵌入式实践 → 工程应用”的顺序学习，并通过项目把各阶段连接起来。

## 推荐实践顺序

1. 用 C 语言实现基础数据结构与常用算法。
2. 在 MCU 上完成 GPIO、定时器、UART、ADC 等外设练习。
3. 增加中断、DMA、任务调度与故障处理。
4. 为驱动和业务逻辑增加可复现的测试。
5. 选择一个完整项目，记录需求、架构、验证结果与问题复盘。
