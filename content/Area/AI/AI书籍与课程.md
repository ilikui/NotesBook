# AI 书籍与课程

书单按学习阶段排列。建议先选一本主教材配合一个实践仓库，不必同时购买或阅读所有书籍。部分书籍有作者或出版社提供的免费配套资料，但不代表整本书可以免费传播。

## 一、入门与通识

| 书籍 | 作者 | 适合人群 | 价值 |
|---|---|---|---|
| Artificial Intelligence: A Modern Approach | Stuart Russell / Peter Norvig | 希望系统理解 AI 全景 | 搜索、逻辑、规划、概率推理与机器学习的经典教材 |
| Artificial Intelligence: Foundations of Computational Agents | David Poole / Alan Mackworth | 想从计算智能角度入门 | 有公开在线版本，适合循序学习 |
| The Hundred-Page Machine Learning Book | Andriy Burkov | 快速建立 ML 全景 | 篇幅紧凑，适合建立术语地图 |

在线教材：
- [Berkeley CS188 AI Textbook](https://inst.eecs.berkeley.edu/~cs188/textbook/)
- [Foundations of Computational Agents](https://artint.info/)

## 二、机器学习与数据科学

| 书籍 | 作者 | 价值 |
|---|---|---|
| Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow | Aurélien Géron | 从数据处理到模型训练的实战教材 |
| Pattern Recognition and Machine Learning | Christopher Bishop | 概率机器学习经典理论教材 |
| The Elements of Statistical Learning | Hastie / Tibshirani / Friedman | 统计学习理论与方法，作者提供在线资料 |
| Python for Data Analysis | Wes McKinney | Pandas 数据处理基础 |

配套资料：
- [ESL 官方在线资料](https://hastie.su.domains/ElemStatLearn/)
- [Hands-On ML 代码仓库](https://github.com/ageron/handson-ml3)
- [Python Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/)

## 三、深度学习

| 书籍 | 作者 | 价值 |
|---|---|---|
| Deep Learning | Ian Goodfellow / Yoshua Bengio / Aaron Courville | 深度学习理论基础，作者提供在线版本 |
| Dive into Deep Learning | Aston Zhang 等 | 理论、公式、代码和练习结合 |
| Deep Learning with Python | François Chollet | 从 Keras 实践理解深度学习 |
| Understanding Deep Learning | Simon J. D. Prince | 现代深度学习直觉与数学解释 |

配套资料：
- [Deep Learning 在线书](https://www.deeplearningbook.org/)
- [Dive into Deep Learning 中文版](https://zh.d2l.ai/)
- [D2L GitHub](https://github.com/d2l-ai/d2l-zh)
- [Understanding Deep Learning 在线版](https://udlbook.github.io/udlbook/)

## 四、大模型与 AI 工程

| 书籍 | 作者 | 价值 |
|---|---|---|
| Natural Language Processing with Transformers | Lewis Tunstall 等 | Transformer 与 Hugging Face 工具实践 |
| Build a Large Language Model (From Scratch) | Sebastian Raschka | 从零实现 GPT 类语言模型，理解训练细节 |
| AI Engineering | Chip Huyen | 基础模型应用、评估、RAG、Agent 与生产工程 |
| Designing Machine Learning Systems | Chip Huyen | 数据、部署、监控和机器学习系统设计 |
| Hands-On Large Language Models | Jay Alammar / Maarten Grootendorst | 用可视化和案例理解 LLM |

配套资料：
- [Build an LLM from Scratch 配套代码](https://github.com/rasbt/LLMs-from-scratch)
- [AI Engineering 配套资源](https://github.com/chiphuyen/aie-book)
- [Full Stack Deep Learning](https://fullstackdeeplearning.com/)

## 五、中文优质教材与课程
- [《神经网络与深度学习》邱锡鹏](https://nndl.github.io/)：中文理论教材与配套资料。
- [《动手学深度学习》中文版](https://zh.d2l.ai/)：中文系统教材，适合边学边练。
- [李沐：动手学深度学习课程](https://space.bilibili.com/1567748478)：配合教材学习。
- [Datawhale 开源学习社区](https://github.com/datawhalechina)：中文开源课程与实践项目。
- [Dive into LLMs](https://github.com/InternLM/Tutorial)：大模型相关教程与实践入口；查看仓库最新课程说明。
- [面向开发者的 LLM 入门课程](https://github.com/mlabonne/llm-course)：从基础到进阶的开源学习材料。

## 阅读建议
- 入门阶段：选择《Hands-On Machine Learning》或《动手学深度学习》作为主线。
- 理论进阶：根据薄弱点补《Deep Learning》或《Pattern Recognition and Machine Learning》。
- 大模型阶段：先学 Transformer，再读 LLM 工程类书籍并运行配套代码。
- 研究阶段：教材建立框架，论文理解前沿，复现实验检验理解。
