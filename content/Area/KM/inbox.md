# 搜集箱（Inbox）

这里用于**快速捕捉、暂存和待处理**的灵感、网页、问题与任务。搜集箱不是长期仓库，也不要求记录时就完成分类。

> [!important] 使用原则
> 先捕捉，后处理；定期清空，不把搜集箱变成第二个永远整理不完的收藏夹。

## 快速记录模板

\`\`\`markdown
## 一句话标题
- 来源：
- 记录时间：
- 为什么值得关注：
- 下一步：
\`\`\`

不需要每项都填。灵感刚出现时，至少留下标题、核心内容或来源中的一项，确保未来能够理解。

## 处理流程

\`\`\`mermaid
flowchart TD
    A[新信息 / 灵感] --> B[放入搜集箱]
    B --> C{下一步是什么?}
    C -->|需要执行| D[转成任务或项目行动]
    C -->|值得理解| E[阅读并写文献笔记]
    C -->|形成自己的观点| F[创建独立知识笔记]
    C -->|以后可能有用| G[整理到资源或归档]
    C -->|无价值 / 重复| H[删除]
    D --> I[从搜集箱移除]
    E --> I
    F --> I
    G --> I
\`\`\`

## 每日清理

- [ ] 处理有明确截止时间或行动要求的条目。
- [ ] 删除重复、过时或无法判断价值的收藏。
- [ ] 给有价值的材料补上来源和一句话说明。
- [ ] 将需要长期维护的观点整理到对应专题，并建立内部链接。
- [ ] 让已经处理的条目离开搜集箱。
