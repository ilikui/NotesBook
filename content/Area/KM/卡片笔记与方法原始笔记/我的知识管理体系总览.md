# ▎ 我的知识管理体系总览

原始 Flomo：https://v.flomoapp.com/mine/?memo_id=MjQ3Nzc0NDE4

▎ **我的知识管理体系总览**

整个体系跑在一条循环链上：输入 → 整理 → 存储 → 输出 → 实践 → 反馈 → 输入

**输入层**（怎么把外部信息抓进来）

- 闪念笔记：捕捉闪现的想法（Inbox兜底）

- 文献笔记：精选摘录，不是抄书

- 堆问题法：带着问题驱动阅读，不是从头翻到尾

- 阅读框架：SQ3R/SQ4R（浏览→提问→阅读→复述→复习）


**整理层**（怎么加工成自己的东西）

- 原子性：一条卡片只装一个知识点

- 用自己的话写一遍（费曼检验）

- 标注来源，留下回头路

- 区分摘录和自己的想法


**存储层**（怎么管理卡片资产）

- Flomo：主笔记库，Inbox→Area→Project流动

- SuperMemo：间隔重复调度，长期记忆加固

- Notion：项目级管理和规划

- 标签层级：# Inbox/xx → # Area/xx → # Project/xx

- 双链：关联时注明为什么有关


**输出层**（怎么变成产品）

- 攒够卡片确定写作主题

- 卡片→初稿→嵌入上下文

- 1000问体系（对一个领域提出1000个问题，通过回答掌握）

- 专栏/课程/第二职业内容


**实践层**（怎么用起来）

- 间隔重复调度（SuperMemo/ANKI）

- 在实践中检验知识是否真的理解

- 建立知识与行动之间的循环


**反馈层**（怎么迭代系统本身）

- 定期回顾旧笔记，找张力/矛盾/空白

- 每完成一个1000问主题，复盘方法论哪里可以优化

- 系统本身也要迭代，不做死框架
