# 知识管理工具

工具选型应从任务出发，而不是从功能列表出发。收集、长文阅读、间隔复习、双向链接和网页发布是不同需求；一个工具未必需要覆盖所有环节。

## 按任务选择

| 任务 | 可考虑的工具 | 选择时关注 |
|---|---|---|
| 临时捕捉与快速记录 | 轻量笔记、手机备忘录、收件箱 | 记录是否足够快，导出是否方便 |
| 长文渐进阅读 | SuperMemo 或普通阅读器配合阅读清单 | 是否支持分段处理、排序和回访 |
| 间隔重复与主动回忆 | Anki 等闪卡工具 | 卡片是否简洁，复习负担是否可持续 |
| 双向链接与本地 Markdown | Obsidian、Logseq 等 | 文件可迁移性、链接、搜索和插件依赖 |
| 结构化专题与协作 | Notion 等 | 数据库、权限、协作和导出需求 |
| 公开发布数字花园 | Quartz、Hugo 等静态站点方案 | Markdown 兼容性、构建流程、部署和维护成本 |

以上是按典型用途划分的候选方向，并非排名；具体功能、平台支持和插件兼容性可能随版本变化，选型前应查看项目当前文档。

## 渐进阅读相关资源

- [SuperMemo Guru](https://supermemo.guru/wiki/SuperMemo_Guru)：关于 SuperMemo 与学习方法的资料。
- [Buboflash](https://buboflash.com/)：可进一步评估的记忆与学习工具。

选择时应确认当前维护状态、数据导出方式、支持平台和隐私政策。不要仅凭历史介绍判断工具仍然可用或适合自己的环境。

## 推荐的轻量组合

对于以 Markdown 为基础、希望长期维护并发布知识库的工作流，可以先采用：

1. **捕捉：** 用一个收件箱统一保存灵感与待处理材料。
2. **阅读：** 使用手边的阅读器，保留来源、阅读进度和待解决问题。
3. **提炼：** 在 Markdown 中写自己的解释，并链接到相关专题。
4. **记忆：** 仅为需要准确回忆的知识制作少量闪卡。
5. **发布：** 经过核对和整理后，再将适合公开的页面纳入网站。

先让流程稳定运行，再决定是否增加新工具。工具数量越多，跨工具同步、搜索和维护的成本也可能越高。

## 工具评估清单

- [ ] 能否完整导出自己的笔记和附件？
- [ ] 是否支持常用格式，避免数据被单一工具锁定？
- [ ] 搜索和链接能否满足实际规模？
- [ ] 是否清楚云端同步、隐私和备份机制？
- [ ] 插件或自动化失效后，核心资料是否仍可访问？
- [ ] 维护成本是否低到足以长期坚持？
