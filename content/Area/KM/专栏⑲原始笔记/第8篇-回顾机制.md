# 专栏⑲·第8篇：回顾机制——被动回顾怎么设计

原始 Flomo：https://v.flomoapp.com/mine/?memo_id=MjUxNzEzMjQw

**专栏⑲·第8篇：回顾机制——被动回顾怎么设计**

▎ **为什么回顾是闭环的命门**<br>
6 层闭环里最容易被跳过的就是反馈层——输入/整理/存储/输出都有动力，回顾没有。你的原则：「不回顾则无意义」（卡片规则第 7 条：定期回顾）。

▎ **主动回顾 vs 被动回顾**

- 主动回顾：你想起去翻——靠意志力，会断
- 被动回顾：系统到点喂给你——不靠意志力，能持续
- 7/27 三问①你问过自己：「所有回顾都靠主动翻，如果设计一个被动回顾机制，做成什么样？」

▎ **被动回顾三件套（flomo 已具备）**

1. 每日回顾：flomo 每天挑几条历史笔记推给你——低成本重遇
2. 那年今日：同月同日的旧笔记端出来——时间维度的连接
3. 每日三问：每天三个专题问题——回顾即输出

▎ **回顾的四个层次**

1. 重读（看到了）：每日回顾 / 翻旧笔记——最低成本，防止遗忘
2. 重组（串起来了）：发现 N 张卡说同一件事 → 织成专栏（输出层的入口）
3. 重写（改进了）：旧笔记过时了 → 更新 / 合并——文档需要持续回顾和深化
4. 重连（用到新场景）：旧知识套到新问题——过去写的正好解决现在的

▎ **三个坑**

1. 回顾只读不写：看了没产出 = 无效回顾——每次回顾至少动一处（改 / 链 / 删）
2. 只回顾最近的：翻来翻去都是近一个月——要定期翻到一年前
3. 把回顾当任务堆：一周攒 7 天没回，回不过来就放弃——小步高频，每天 5 分钟

▎ **一句话**：回顾是闭环的命门——被动机制（每日回顾 / 那年今日 / 每日三问）不靠意志力；回顾四层次（重读→重组→重写→重连），每次至少动一处，让旧笔记持续活着。
