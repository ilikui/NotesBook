**专栏⑲·第5篇：存储层——标签体系、PARA、双链**

▎ **存储层在干什么**<br>
整理好的卡片放进一个「找得到、连得上」的体系——存储的底线是检索，上限是网络。

▎ **三套存储工具**

1. 标签体系：你的 28 Inbox + 4 Area + 2 Project 两级标签（8/8 起标签统一放末尾）——分类管理 + 层级
2. PARA：Projects / Areas / Resources / Archives——按「用途」而不是「主题」组织（PARA + 26 关键词）
3. 双链：flomo 的 memo 链接——从「文件夹」到「网络」的关键一步

▎ **标签 vs PARA vs 双链，各管什么**

- 标签管「归类」：快速过滤
- PARA 管「位置」：现在在做什么
- 双链管「关系」：和什么有关<br>
  三件套不冲突，各干各的

▎ **你的实证**

- 18 个专栏各自的「Project/工作笔记/」标签（如历史、数学、AI）就是 PARA 的 Projects 落地
- Inbox 分类（任务/日记/问题库/方法…）是 28 标签的骨架
- 8/8-8/9 把所有存量标签从开头搬到末尾——存储规则的一致性维护

▎ **一句话**：存储层三件套——标签管归类、PARA 管位置、双链管关系；「找得到是底线，连得上才是资产」，你的 18 个专栏标签树就是这套体系跑出来的。
