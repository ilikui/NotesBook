# 软考高级1000问：系统架构师与项目管理基础

本篇迁移 Flomo 中两份软考高级问题库的首批 20 道基础题。答案采用“定义—原理—计算/判断—易错点”的应试结构。软考大纲、教材版本和当年考试政策可能变化，正式备考应以当年官方考试说明和指定教材为准。

## 一、系统架构师（Q1–Q10）

### Q1. 计算机体系结构与计算机组成有什么区别？

**答案：** 体系结构关注程序员可见的机器属性，例如指令集、数据类型、寻址方式和异常模型；计算机组成关注这些属性如何由硬件实现，例如流水线、Cache、控制器和总线。记忆：体系结构回答“机器对软件承诺什么”，组成回答“硬件如何兑现”。

### Q2. Flynn 分类法如何分类？GPU 属于哪一类？

**答案：** Flynn 分类依据指令流和数据流数量，分为 SISD、SIMD、MISD、MIMD。GPU 的大规模并行计算通常体现 SIMD/SIMT 风格：多个执行单元对不同数据执行相同或相似操作。现代 GPU 实现并非简单传统 SIMD，考试答题可先给出经典分类，再说明 SIMT 是实际实现模型。

### Q3. RISC 与 CISC 的核心区别是什么？

**答案：** RISC 倾向于较简单、规则的指令、较多通用寄存器和 Load/Store 结构，便于流水线和硬件实现；CISC 指令集更复杂，指令长度和寻址方式更丰富。现代处理器常把复杂指令解码为内部微操作，因此不能简单认为 CISC 一定慢、RISC 一定快。

### Q4. 流水线的结构、数据和控制冒险是什么？

**答案：**

- 结构冒险：多个流水级争用同一硬件资源。
- 数据冒险：后续指令依赖前序指令尚未产生的结果。
- 控制冒险：分支跳转使下一条指令地址不确定。

常用处理方式包括资源复制、暂停/插入气泡、转发、分支预测和流水线冲刷。理想 k 级流水线执行 n 条指令的周期数近似为 k+n−1（假设每级一个周期、无冒险），实际还要加上停顿和分支代价。

### Q5. Cache 命中率如何影响平均访问时间？

**答案：** 简化模型为：

~~~~text
Tavg = H × Tcache + (1-H) × Tmemory
~~~~

命中率 H=95%、Cache 访问 1ns、未命中主存访问 10ns 时，平均时间为 0.95×1 + 0.05×10 = **1.45ns**。注意真实系统还可能有多级 Cache、写缓冲、未命中惩罚和并行访问，公式需按题目定义理解。

### Q6. Cache 写直达与写回有什么区别？

**答案：** 写直达（Write Through）在写 Cache 的同时更新下一级存储，数据一致性较容易维护，但写流量较大；写回（Write Back）先更新 Cache 并标记脏块，替换时再写回，能减少下级写流量，但一致性和故障处理更复杂。涉及 DMA 或多核共享时，还要考虑 Cache coherency、flush/invalidate 和内存屏障。

### Q7. FCFS、SSTF、SCAN、C-SCAN 哪种可能导致饥饿？

**答案：** SSTF 每次选择距离当前磁头最近的请求，远端请求可能长期得不到服务，存在饥饿风险。SCAN 像电梯一样双向扫描；C-SCAN 主要单向服务后回到起点，等待时间更均匀。实际磁盘和 SSD 调度还受设备内部机制影响，考试重点是经典磁头调度模型。

### Q8. k 级流水线执行 n 条指令的加速比如何计算？

**答案：** 理想非流水执行时间近似为 k·n 个阶段周期；理想流水执行时间为 k+n−1 个阶段周期。因此：

~~~~text
Speedup = (k × n) / (k + n - 1)
~~~~

当 n 很大时，加速比趋近 k。它表示理想情况下流水线重叠执行带来的吞吐提升，不意味着单条指令延迟也缩短为原来的 1/k。

### Q9. 进程与线程有什么区别？

**答案：** 进程通常是资源分配和保护的基本单位；线程是进程内的执行流，是调度器管理的基本执行单位。线程共享进程地址空间和部分资源，切换通常比进程切换轻，但线程仍有独立栈、寄存器上下文和调度状态。线程共享带来通信便利，也带来竞态、死锁和同步问题。

### Q10. 死锁的四个必要条件是什么？银行家算法做什么？

**答案：** 死锁必要条件为互斥、占有并等待、不可剥夺、循环等待。破坏任一条件可用于预防死锁。银行家算法不是简单检查单个进程需求是否小于可用资源，而是模拟一个安全序列：反复寻找剩余需求不超过当前 Available 的进程，假设其完成并释放资源；若最终所有进程都能完成，则系统处于安全状态。

## 二、信息系统项目管理师（Q11–Q20）

### Q11. 国家信息化建设常说的“六要素”是什么？

**答案：** 常见教材表述包括信息资源、信息网络、信息技术应用、信息技术和产业、信息化人才、信息化法规政策等。不同教材的概括口径可能略有差异，答题时应按当年教材原文表述。记忆时要理解六要素分别覆盖资源、基础设施、应用、产业、人才和制度保障。

### Q12. 信息化体系中“信息资源”为什么重要？

**答案：** 信息技术和网络提供能力，信息资源则承载业务价值。若只有网络和系统而缺乏准确、可共享、可治理的数据，信息化很难产生持续效益。因此在常见教材框架中，信息资源通常被强调为核心资源，但不要把它误解为唯一决定因素。

### Q13. 电子政务与电子商务有什么区别？

**答案：** 电子政务以政府公共管理和公共服务为核心，常按 G2G、G2B、G2C、G2E 等关系分类；电子商务以商业交易和价值交换为核心，常见 B2B、B2C、C2C 等模式。两者都使用数字平台，但主体、目标、监管和价值实现方式不同。

### Q14. CSF、SST、BSP 三种企业信息化规划方法有什么区别？

**答案：**

- CSF（关键成功因素法）：从组织关键成功因素出发识别信息需求。
- SST（战略目标集转化法）：把组织战略目标转化为信息系统目标。
- BSP（企业系统规划法）：强调自上而下识别业务目标、自下而上分析数据与系统支持。

选择方法应看企业战略清晰度、业务流程成熟度和数据治理基础，不能把三种方法理解为互斥的唯一方案。

### Q15. 信息系统生命周期通常有哪些阶段？

**答案：** 常见阶段为规划、分析、设计、实施、运行维护。规划阶段进行可行性研究和总体方向判断；分析阶段明确需求；设计阶段形成架构和详细方案；实施阶段开发、测试和部署；运维阶段监控、修复、升级并最终退役。

### Q16. 项目章程与项目范围说明书有什么区别？

**答案：** 项目章程由发起人或授权主体发布，正式批准项目并授权项目经理使用组织资源；范围说明书进一步描述项目边界、可交付成果、验收标准和不包含的内容。章程解决“为什么启动、谁授权”，范围说明书解决“具体做什么、不做什么”。

### Q17. 项目变更控制为什么需要 CCB？

**答案：** 变更会影响范围、进度、成本、质量、资源和风险。CCB（变更控制委员会）通过授权的治理机制评估变更影响并作出批准、拒绝或延期决定，避免未经评估的变更破坏项目基线。CCB 成员组成和审批权限应由组织治理制度确定，不是标准要求必须多人或某一种固定形式。

~~~~mermaid

  A[提出变更申请] --> B[登记与初审]
  B --> C[影响分析：范围 / 进度 / 成本 / 风险]
  C --> D[CCB 或授权人决策]
  D -->|批准| E[更新基线并实施]
  D -->|拒绝 / 暂缓| F[记录原因并通知]
  E --> G[验证变更效果与归档]
~~~~

### Q18. WBS 的 100% 原则是什么？

**答案：** WBS 的下一层工作分解项应完整覆盖上一层范围内的全部工作，不能遗漏，也不能重复计算。WBS 以可管理、可估算、可分配和可验收为目标，分解粒度应保持一致，并与可交付成果和责任人对应。

### Q19. 范围蔓延与镀金有什么区别？

**答案：** 范围蔓延是未经适当控制地增加项目范围或需求；镀金是团队未经客户/项目授权，主动增加合同或范围之外的功能。两者都会增加成本、进度和质量风险，必须通过需求管理、变更控制和验收标准约束。

### Q20. 关键路径与总浮动时间如何理解？

**答案：** 关键路径是决定项目最短工期的最长逻辑路径。关键活动通常总浮动时间为零；非关键活动在不影响项目完工日期的前提下有一定延迟空间。常见计算：总浮动时间 TF = LS−ES = LF−EF。计算时要先画网络图、做正推求最早时间、再逆推求最迟时间。

## 应试答题模板

1. 先给准确术语定义。
2. 再解释机制或因果关系。
3. 计算题写出公式、代入过程和单位。
4. 方案题明确约束、取舍、风险与验证。
5. 最后点出适用边界，避免绝对化表述。
