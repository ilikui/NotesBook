# Project（项目）

项目是为实现明确目标而开展的一组任务，通常具有交付物、时间边界和完成条件。项目页面应帮助推进工作，而不只是记录背景资料。

完整入口见 [[Project/index|项目总览]]。

## 项目页面建议结构

1. **目标与范围：** 明确要解决的问题，以及不包含的内容。
2. **交付物与验收：** 定义什么结果代表完成。
3. **下一步行动：** 记录可执行、可验证的任务。
4. **关键决策：** 保存决策理由、约束与替代方案。
5. **参考资料：** 链接来源和相关知识笔记。
6. **复盘：** 记录结果、问题与可复用经验。

## 项目结束时

- 验收交付物并记录未完成事项。
- 将通用经验提炼到相关 [[Area|领域]]。
- 将可复用资料整理到 [[Resource|资源区]]。
- 将项目本身移入 [[Archive|存档区]]，保留必要的历史记录。

## 相关

- [[Area]]：长期维护的能力与责任
- [[Resource]]：参考资料与灵感
- [[Archive]]：已完成或暂停的项目
