# 开发工具与工程工具链

工具应服务于工作流，而不是反过来决定工作流。选择工具时重点考虑目标平台、团队标准、许可证、可重复构建、数据可追溯和自动化能力。

## 工具分层

| 环节 | 常见工具 | 主要用途 |
|---|---|---|
| 编辑与开发 | VS Code、STM32CubeIDE、Keil、IAR | 编辑、编译、调试 MCU 软件 |
| AUTOSAR 配置 | DaVinci Developer / Configurator、EB tresos Studio | 配置 SWC、BSW、通信与生成代码；具体能力依版本和授权而异 |
| 模型开发 | MATLAB / Simulink、Embedded Coder | 建模、仿真、代码生成与验证 |
| 总线分析 | CANoe | 网络仿真、报文分析、诊断与测试 |
| 自动化 | Python | ARXML 批处理、数据转换、报告生成和 CI 辅助 |
| 版本管理 | Git | 变更追踪、分支协作、代码审查 |
| 阅读与信息输入 | 微信读书、RSS 阅读器 | 阅读、划线、订阅与来源管理 |
| 知识管理 | Flomo、Notion、Obsidian、OneNote、Zotero、SuperMemo | 捕捉、组织、文献管理和间隔重复；按用途选择，不必重复维护同一份知识 |

## 硬件调试与验证

- **示波器**：观察电压随时间变化，分析上升沿、振铃、时序和电源完整性。
- **万用表**：测量电压、电流、电阻和通断，适合基础电气检查。
- **逻辑分析仪**：捕获数字信号与协议时序，适合 SPI、I²C、UART 等接口排查。
- **热成像仪**：定位异常发热区域，辅助发现功耗、短路或散热问题。
- **开发板**：用于验证驱动、外设、启动流程和最小可复现案例。

## Windows 命令行下载工具

GNU Wget 可在命令行中下载 HTTP、HTTPS 和 FTP 资源。使用前确认下载来源可信，并检查文件哈希或数字签名（如果发布方提供）。

- [Wget for Windows 下载入口](https://eternallybored.org/misc/wget/)

示例：

```powershell
# 下载单个文件
wget.exe https://example.com/file.zip

# 指定输出文件名
wget.exe -O package.zip https://example.com/package.zip
```

## 选型与治理检查

1. 明确工具对应的任务、输入、输出和责任人。
2. 记录工具版本、插件版本、许可证和目标平台。
3. 关键配置尽量版本化，避免只保存在个人电脑或 GUI 工程中。
4. 自动生成文件标明来源和生成方式，不手工修改生成产物。
5. 对关键链路建立可复现脚本、日志和验收标准。
6. 不在公开仓库提交许可证密钥、API Token、私有服务器地址或内部配置。
