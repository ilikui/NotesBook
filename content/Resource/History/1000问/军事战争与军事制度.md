# 历史上下五千年1000问：军事战争与军事制度

本篇从 Flomo「专栏⑱·第1篇：军事与对外」抽取军事战争史、军事制度演变和游牧军事三个板块，整理 NotesBook 连续编辑编号 Q85–Q94。原始题目中出现的兵力、伤亡、武器射程等数字，若缺少可靠交叉证据，不当作确定事实；对后世叙事与现代研究的差异单独说明。

## 一、关键战役：战争结果如何形成

### Q85. 牧野之战为什么会成为商周更替的关键节点？“前徒倒戈”能否证明商军全是奴隶？

**答案：** 牧野之战通常被置于公元前 11 世纪中叶，是周武王伐商并击败商王帝辛（后世称纣王）的关键战役。西周早期青铜器利簋铭文记有“武王征商”及甲子日相关信息，是研究伐商年代和事件的重要出土材料。

**需要区分三层证据：**

1. **可以较有把握确认的核心：** 周人发动伐商战争并取得决定性胜利，商王朝政治中心随之崩溃，周建立新的统治秩序。
2. **传世文献的叙事：** 《尚书》《史记》等记载商军阵前倒戈、周军乘势进攻。“前徒倒戈”成为商军士气和统治危机的象征。
3. **不能直接推出的结论：** 不能据此断言商军全部由奴隶、囚犯组成，也不能把倒戈简单解释为“奴隶没有忠诚”。军队构成、参战人数和战场细节仍需结合甲骨文、金文与传世文献判断。

**历史解释：** 周的胜利不仅是一次战场胜负，也与周长期扩张、联盟经营、商周政治关系变化以及商王权威受损有关。把“失民心”当作道德结论可以理解传统叙事，但若要解释战争结果，还要分析政治联盟、军事组织和资源动员。

### Q86. 长平之战（前 260 年）赵军为何惨败？白起坑杀“40 万”是否可以当作精确数字？

**答案：** 长平之战是秦、赵争夺上党及战略优势的长期战争，赵军最终遭到决定性失败。秦将白起在战后处置大量赵军降卒，是战役记忆中最具争议的部分。

**赵国失败的多因素解释：**

- 秦国长期推进东向战略，能够持续调动兵力、粮食和盟友资源。
- 赵国在战略判断、外交协调和长期消耗能力上处于不利位置。
- 廉颇采取坚守策略，赵王后来更换主将为赵括；但不能把战败完全归咎于“纸上谈兵”，也不能忽略秦国的综合国力与战略准备。
- 秦军对降卒的大规模处置，既有军事安全和后勤压力的背景，也体现了战国战争的极端暴力，不能简单美化成“理性决策”。

**数字审读：**《史记》记载赵军降卒被坑杀四十余万。现代研究对战国军队统计口径、军队中非战斗人员比例、数字是否包含战前战后损失等提出不同看法。悉尼科技大学开放研究论文指出，不能只因数字看起来庞大就简单认定古籍夸大；但同样不应把古代记载直接换算成现代精确伤亡统计。

**结论：** 记住“赵军惨败、降卒遭大规模杀戮”这一历史核心；对四十余万的具体数字保留史料口径意识。

### Q87. 垓下之战中的“四面楚歌”为什么会打击项羽军心？它是整场楚汉战争胜负的唯一原因吗？

**答案：** 垓下之战发生于楚汉战争末期。根据《史记·项羽本纪》，项羽军队兵少粮尽，被汉军及诸侯军多重包围，夜间听到四面楚歌，项羽由此惊疑楚地已被汉军控制。

**“四面楚歌”的作用：**

1. **信息与认知冲击：** 楚歌使项羽及其部属感到楚地支持基础可能已经瓦解，强化了孤立感。
2. **士气与凝聚力：** 军队不仅需要战斗力，还需要对继续作战是否有意义的判断。粮尽、被围、盟友倒向汉方等因素共同削弱了楚军抵抗意志。
3. **心理战不是全部解释：** 汉军在战略联盟、兵力部署、后勤和持续作战能力方面已占优势；垓下只是长期楚汉战争的最后阶段，不是靠唱歌单独取胜。

**史料边界：** 《史记》记载“四面皆楚歌”，但没有明确记载这是张良预先设计的完整心理战计划。后世通俗叙事常把细节补充得更戏剧化，引用时应回到《史记》原文。

### Q88. 赤壁之战究竟是黄盖火攻取胜，还是曹军疫病导致撤退？

**答案：** 公元 208 年前后，孙刘联军在长江中游与曹操军队交战，赤壁之战阻止了曹操迅速控制江南，为魏、蜀、吴三方格局的形成创造条件。

**不能把“火攻”和“疫病”设成非此即彼：**

- 《三国志》及裴松之注所保存的不同记载，对火攻、曹军撤退和疫病的强调并不完全相同。
- 孙吴方面的叙事突出黄盖诈降、火船突袭和曹军舰船受焚。
- 曹操致孙权书信相关记载则强调军中疾病，称自己烧毁船只以免其落入孙权手中。
- 军队在陌生水土环境下发生疾病、长期行军疲惫、指挥协同困难和水战经验不足，都可能放大火攻造成的损失。

**更稳妥的判断：** 火攻是传统记载中的重要战术环节，疾病与撤退也有史料依据；各因素具体权重难以精确还原。所谓“血吸虫病是赤壁胜负的决定因素”缺乏足够证据，不应写成定论。

### Q89. 淝水之战（383 年）中，前秦为什么会在兵力占优的情况下败给东晋？

**答案：** 前秦皇帝苻坚南征东晋，东晋由谢安等组织防御，谢玄率领的北府兵在淝水一线取得胜利。此战打击了前秦的统一进程，也加速了其内部政治和族群联盟的瓦解。

**主要解释：**

1. **前秦政权整合不足：** 苻坚统合了多个族群和政治力量，名义上的大帝国不等于军队拥有统一的组织认同和稳定指挥体系。
2. **战场部署与指挥失误：** 传统史书记载前秦军队后撤让东晋渡河，撤退过程发生混乱；朱序在秦军阵后喊出败讯，被认为进一步加剧恐慌。
3. **东晋军队组织与士气：** 北府兵具有较强战斗力，东晋利用前秦部署失误发动反击。
4. **战后政治后果：** 前秦的军事失败使原本被压制的地方势力和族群领袖重新行动，政权迅速分裂。

**数字审读：** “苻坚百万大军对东晋八万”是传统叙事中常见的概括，现代研究对兵力数字、会战规模和具体日期均有讨论。不能仅凭“百万对八万”就把胜利解释为少数精兵创造奇迹。

## 二、军事制度：国家怎样组织军队

### Q90. 唐代府兵制为什么逐渐让位于职业化、长期驻防的军队？

**答案：** 唐初府兵制是以地域性军府组织为基础的兵役制度，士兵平时与家庭和生产生活相联系，在需要时承担军事任务。它不是简单的“农民农闲训练、自带所有军需”，而是包含军府编制、兵役义务、装备和国家供给等制度安排。

**制度变化：**

- 唐初约六十年，府兵是唐军的重要骨干。
- 7 世纪后期起，边疆长期驻防和远距离轮戍使临时性兵役制度承压。
- 8 世纪前期，边疆军队越来越依赖长期服役的职业兵和募兵。
- 安史之乱爆发前，府兵已不再是唐朝军事力量的唯一核心；安史之乱后，地方藩镇和职业军队的重要性进一步上升。

**不能过度简化为“土地兼并导致府兵制崩溃”：** 土地制度、边防任务、兵役负担、军队驻防距离、财政供给和兵员招募方式共同推动制度转型。剑桥大学《中国历史杂志》关于唐代军事制度的研究，将唐代军事力量概括为府兵主导、过渡、职业军队和地方驻军主导的阶段性变化。

### Q91. 宋代“重文轻武”是否意味着宋朝不重视军队，甚至主动放弃军事能力？

**答案：** 这种说法过于简单。宋朝的核心军事制度取向是加强中央对军队的控制、削弱地方将领形成私人军队的可能性，而不是取消军队或完全放弃军事投入。

**制度设计及其代价：**

- 中央政府直接招募、训练、装备和支付禁军等军队。
- 枢密院等机构参与军事决策，文官与武将的权力关系经过制度化安排。
- 将领调动、兵将分离等制度有助于防止军事将领长期掌握地方力量，但也可能损害部队稳定性和将领对部队的熟悉程度。
- 宋代军费长期是财政的重要组成部分，宋朝也持续建设防御体系、发展水军和使用火器。

**更准确的结论：** 宋代不是“没有军事”，而是军事组织高度中央化，主要服务于防御和内部安全。制度在限制地方军阀的同时，也可能增加跨层级协调成本，影响某些进攻行动的效率。

### Q92. 明代卫所制为什么发生变化？它是因为腐败而“一夜崩溃”的吗？

**答案：** 明初卫所制以军户世袭服役和卫所编制为基础，并与屯田、军需供给、军籍管理等制度相连。它不是单纯的“每名士兵分地自给”，也不是在某一年突然整体消失。

**长期变化过程：**

1. 军户世袭制度持续存在，但不同地区、时期的实际执行情况并不相同。
2. 军屯产出和军队供给难以始终满足驻军需求，国家逐步增加其他补给方式。
3. 土木堡之变（1449 年）后，军队补充、边防和指挥体系面临压力，制度调整加速。
4. 16 世纪中期，募兵和雇佣兵在不少地区日益重要；卫所仍继续承担军籍、后勤、管理等功能。
5. 到明末，卫所原有的作战组织作用已大幅变化，但不能说卫所作为制度和行政组织在某一时点完全消失。

**研究更新：** 加州大学伯克利分校的博士论文《Taming the Army》强调，明代卫所不是静止不变的制度；它在不同战争、财政和社会条件下经历调整。研究者更倾向于讨论转型，而非简单用“腐败导致崩溃”概括。

## 三、草原军事与农耕王朝的边疆关系

### Q93. 汉朝与匈奴长期战争，为什么汉初以和亲为主，汉武帝时期转向大规模主动进攻？

**答案：** 汉初经历秦末战争和社会恢复，国家财政、人口和军队建设尚未达到持续远距离作战的条件；匈奴则拥有适应草原环境的骑兵机动能力。和亲、互市、边境防御和军事行动并非完全互斥，而是不同阶段的政策组合。

**汉武帝时期的变化：**

- 国家经济和财政能力增强，能够支持更大规模的边疆战争。
- 汉朝发展骑兵、改善马政，并通过河西走廊等方向推进战略部署。
- 张骞出使西域的原始任务之一是联络大月氏共同对抗匈奴；虽然军事联盟目标未能实现，却扩大了汉朝对中亚的地理和政治认知。
- 汉朝逐步在河西及西域设置军事据点，改变了与匈奴的战略态势。

**不要误解为“得到汗血宝马才打赢匈奴”：** 战马来源只是因素之一。军队训练、后勤、财政、边疆据点、将领和外交关系同样重要。关于张骞与汉朝向中亚扩张，可参阅剑桥大学 Craig Benjamin 对相关史事的研究。

### Q94. 蒙古军队为什么能够建立横跨欧亚的帝国？是否只靠“每人三到五匹马、日行百公里、复合弓射程更远”？

**答案：** 蒙古军事优势来自机动能力、组织方式、情报与通信、战术灵活性，以及吸收被征服地区技术和人才的能力。不能把复杂的军事体系简化为几组流行数字。

**关键机制：**

1. **机动与后勤：** 以马匹和草原环境为基础，提高部队快速移动和分散集结的能力；具体行军速度取决于地形、天气、补给和任务，不能把“日行百公里”当作常态。
2. **组织方式：** 十进制编制有助于组织军队、分配指挥责任，并在扩张过程中吸纳不同族群。
3. **战术灵活：** 骑射、诱敌、迂回、包围和分进合击可以组合使用，具体战术随敌情变化。
4. **技术吸收：** 蒙古军队并非只依赖骑兵。攻城工程师、步兵、重骑兵、海军和火药武器都在不同战区发挥作用。
5. **帝国治理与军事动员：** 征服后吸收当地行政、工匠和军事人才，使军队能力超越最初的蒙古草原人口基础。

**结论：** 蒙古军队的强项不是单一武器，而是将机动骑兵、组织制度、情报、攻城技术和多族群资源整合成适应不同战场的军事机器。
