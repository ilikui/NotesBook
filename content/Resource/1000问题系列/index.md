# 1000问知识体系

这里集中整理 Flomo 中长期积累的「1000问 / 1000题 / 10000问」问题库、逐题解答和专题卡片。目标不是只保存题目，而是把每个问题沉淀为可检索、可验证、可复用的知识单元。

> 迁移原则：保留问题原意；合并重复题但记录关联；答案给出原理、适用边界和验证方法；技术内容尽量附 Mermaid 图；未核验的结论明确标注待核验。Flomo 原笔记暂不删除。

## 知识迁移流程

~~~~mermaid
flowchart TD
  A[Flomo 原始笔记] --> B[检索与盘点]
  B --> C[按主题归类]
  C --> D[识别重复问题]
  D --> E[读取完整原文]
  E --> F[补充答案与工程案例]
  F --> G[绘制 Mermaid 图]
  G --> H[写入 NotesBook]
  H --> I[回读核验与交叉链接]
  I --> J[更新迁移清单]
~~~~

## 题目卡片的统一标准

每个问题至少包含：

1. **问题**：保留原始提问，必要时改写为更清晰的表达。
2. **直接答案**：先用一段话回答核心问题。
3. **原理**：解释为什么，给出关键概念、机制或推导。
4. **工程/生活实例**：说明在什么场景会遇到。
5. **验证方法**：给出可执行的实验、计算、日志、规范或资料核验方法。
6. **易错点与边界**：指出版本、平台、前提条件和常见误区。
7. **图示**：用 Mermaid 表达架构、流程、状态或因果关系。
8. **来源与关联**：链接原 Flomo 笔记及 NotesBook 相关主题。

## 去重与答案质量规则

- 同一问题在多个系列出现时，保留一个主答案，其余位置建立链接，不机械复制。
- 「是什么」「为什么」「怎么做」「怎么验证」是不同层次，不能因为关键词相同就合并。
- 规范类答案标注 AUTOSAR 版本、标准文档或供应商实现差异；不把某工具的行为说成标准强制要求。
- 历史、教育等开放问题采用「事实 / 解释 / 争议」结构，不伪造唯一标准答案。
- 原笔记中的数字、版本、术语若缺乏依据，保留为待核验，不直接包装成确定事实。
