# Archive｜归档区

Archive（归档区）存放已完成、已停止维护或暂时不活跃，但仍有检索价值的历史内容。它不是垃圾桶，也不应成为外部文档的无差别镜像。

> [!info] 一句话定位
> **不再活跃，但值得留存的过去。**

## 归档原则

```mermaid
flowchart LR
    A[当前笔记] --> B{仍在持续使用？}
    B -- 是 --> C[Project / Area / Resource]
    B -- 否 --> D{是否值得未来查阅？}
    D -- 是 --> E[Archive]
    D -- 否 --> F[确认后删除]
```
